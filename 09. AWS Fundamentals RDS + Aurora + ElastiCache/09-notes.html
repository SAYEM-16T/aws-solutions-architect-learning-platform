Shohoj kore (library): Ek library te ek-i boi er photocopy onek gulo rakhle beshi lok ekshathe porte pare: eta Read Replica (copy ektu pore update hoy, tai kokhono purono page thakte pare = async). Read Replicas: read scalability (PDF p. 165 (part p. 5))

  • Main DB onek request e hapiye uthle reads scale korte 15 ta porjonto Read Replica.
  • Location: same AZ, cross AZ, ba cross Region (tinta option, mone rakho).
  • Replication ASYNC → reads eventually consistent: replica te data pouchanor age porle purono data pete paro.
  • Replica ke promote kore nijer alada DB banano jay: tokhon replication theke ber hoye jay, writes ney, nijer life cycle.
  • App ke connection string update korte hoy jate sob read replica use kore (protita replica er nijer endpoint).

Use case: reporting / analytics (PDF p. 166 (part p. 6))

  • Production DB normal load nicche. Notun team reporting / analytics chalate chay. Main DB te chalale production slow hobe.
  • Solution: Read Replica banao, reporting app shudhu oi replica theke read korbe → production unaffected.

RDS Multi AZ: Disaster Recovery (PDF p. 168 (part p. 8))

  • Master instance AZ A te, standby instance AZ B te. Replication SYNC: master e lekha change standby te-o lekha holei tobe accept.
  • Ek DNS name: app ek-i nam e kotha bole; master e somossa hole automatic failover standby te. Standby notun master hoy.
  • Failover hoy: AZ loss, network loss, instance ba storage failure (master er).
  • App e manual intervention lage na (app reconnect korte thakle nije-i standby te chole jabe).
  • Scaling er jonno na: standby te keu read-o korte pare na, write-o na; shudhu failover er jonno boshe thake.
  • Read Replica-ke-o Multi AZ hisebe setup kora jay (DR er jonno). Instructor: common exam question.

Also known as dogpiling, the thundering herd effect is what happens when many different application processes simultaneously request a cache key, get a cache miss, and then each hits the same database query in parallel. The more expensive this query is, the bigger impact it has on the database. If the query involved is a top 10 query that requires ranking a large dataset, the impact can be a significant hit.
