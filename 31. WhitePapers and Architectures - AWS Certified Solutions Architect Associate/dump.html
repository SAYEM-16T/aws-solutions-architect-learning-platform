31·1D-Q402SAA-C03 dump · Q402

A company has multiple AWS accounts that use consolidated billing. The company runs several active high performance Amazon RDS for Oracle On-Demand DB instances for 90 days. The company's finance team has access to AWS Trusted Advisor in the consolidated billing account and all other AWS accounts. The finance team needs to use the appropriate AWS account to access the Trusted Advisor check recommendations for RDS. The finance team must review the appropriate Trusted Advisor check to reduce RDS costs. Which combination of steps should the finance team take to meet these requirements? (Select TWO.)

Choose 2 answers

Correct: B, C. Why it is right

  • B: Consolidated billing er payer (management) account theke Trusted Advisor e sob linked account er RDS check eksathe dekha jay; Reserved Instance recommendation puro billing family hisebe calculate hoy.
  • C: High performance RDS 90 din dhore On-Demand e cholche = steady workload; RDS Reserved Instance Optimization check bole RI kinle koto khoroch kombe (Trusted Advisor er Cost optimization category, PDF p. 860).

Judgement call: keu keu bole A (je account e RDS chole sekhan theke); accepted answer B + C.

Why the other options are wrong

  • A. Ekta account theke shudhu oi account er instance dekha jay; consolidated billing account theke sob account eksathe dekha jay. (Judgement call, accepted B.)
  • D. Idle DB Instances check unused DB khoje; ekhane instance gulo active, tai eta kaje ashbe na.
  • E. Redshift Reserved Node check Redshift er jonno; question RDS niye.

Keyword: active RDS On-Demand for 90 days + consolidated billing + reduce RDS costs → payer account Trusted Advisor + RDS RI Optimization check

Dump explanation (English)

B. Use the Trusted Advisor recommendations from the consolidated billing account to see all RDS instance checks at the same time. The consolidated billing account has access to all the other AWS accounts that use consolidated billing. Using the Trusted Advisor recommendations from the consolidated billing account will allow the finance team to see all RDS instance checks for all accounts at the same time. C. Review the Trusted Advisor check for Amazon RDS Reserved Instance Optimization. The Trusted Advisor check for Amazon RDS Reserved Instance Optimization provides recommendations for purchasing reserved instances to reduce RDS costs. By reviewing this check, the finance team can identify which RDS instances can be converted to reserved instances to save costs.

31·2D-Q440SAA-C03 dump · Q440not in course

A company is subscribed to the AWS Business Support plan. Compliance rules require the company to check on AWS infrastructure health before deployments can proceed. The company needs a programmatic and automated way to check on infrastructure health at the beginning of new deployments. Which solution will meet these requirements?

Not in the course: AWS Health API / Health Dashboard course e shekhano hoy na.

Correct: B. Why it is right

AWS Health API AWS service ar tomar account er resource er health event (outage, scheduled change) programmatically dey; Business support ba tar upor e available. Deployment er shurute API call kore issue thakle deployment pause koro.

Note: AWS Health API/Health Dashboard course e shekhano hoy na.

Why the other options are wrong

  • A. Trusted Advisor best-practice check dey (cost, security, limit); AWS infrastructure er current health/outage jananor jonno na.
  • C. Support API support case manage kore; 'open case' thaka mane AWS infrastructure unhealthy na.
  • D. Nijer workload e API call kora AWS infrastructure health check na; ar protiti workload e manual/custom kaj.

Keyword: programmatic check on AWS infrastructure health before deployments → AWS Health API

Dump explanation (English)

The AWS Health API provides programmatic access to the AWS Health information that is presented in the AWS Personal Health Dashboard. You can use the API operations to get information about AWS Health events that affect your AWS services and resources. You can also use the API to enable or disable health-based insights for your organization. You can use the AWS Health API at the start of each deployment to check on AWS infrastructure health and pause all new deployments if the API returns any issues. Reference: https: //docs.aws.amazon.com/health/latest/APIReference/Welcome.html
