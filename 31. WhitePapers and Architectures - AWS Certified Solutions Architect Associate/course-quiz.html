Which AWS Service analyzes your AWS account and gives recommendations for cost optimization, performance, security, fault tolerance, and service limits?

Correct: A. Why it is right

Trusted Advisor kichu install na korei account er high level assessment kore, ar recommendation dey 6 category te: Cost optimization, Performance, Security, Fault tolerance, Service limits, Operational Excellence (PDF p. 860).

Question er list (cost, performance, security, fault tolerance, service limits) hubohu Trusted Advisor er category.

Why the other options are wrong

  • B. CloudTrail API call/account activity log kore (audit); recommendation dey na.
  • C. IAM user, group, role, permission manage kore; account analyze kore best practice recommendation dey na.
  • D. CloudFormation infrastructure as code diye resource create kore; account analyze kore na.

Keyword: analyzes your AWS account + cost, performance, security, fault tolerance, service limits → Trusted Advisor

Instructor feedback (English)

A: AWS Trusted Advisor provides recommendations that help you follow AWS best practices. It evaluates your account by using checks. These checks identify ways to optimize your AWS infrastructure, improve security and performance, reduce costs, and monitor service quotas.

B: AWS CloudTrail allows you to log, continuously monitor, and retain account activity related to actions across your AWS infrastructure. It provides the event history of your AWS account activity, audit API calls made through the AWS Management Console, AWS SDKs, AWS CLI. You can use CloudTrail to detect unusual activity in your AWS accounts.

C: AWS IAM enables you to manage access to AWS services and resources securely. You can create and manage IAM users, groups, and roles, and use permissions to allow and deny their access to AWS resources.

D: AWS CloudFormation is the de-facto service in AWS for infrastructure as code (IaC). It enables you to create and provision AWS infrastructure deployments predictably and repeatedly.
