12·1U12-Q1Udemy quiz · sec 12 · Q1

You're getting errors while trying to create a new S3 bucket named "dev". You're using a new AWS Account with no S3 buckets created before. And you double-checked and found that you have the correct IAM permissions to create S3 Buckets. What is a possible cause for this?

"dev" নামে একটি নতুন S3 bucket তৈরি করার চেষ্টা করার সময় আপনি error পাচ্ছেন। আপনি একটি নতুন AWS Account ব্যবহার করছেন, যেখানে আগে কোনো S3 bucket তৈরি করা হয়নি। এবং আপনি আবার check করে দেখেছেন যে S3 Buckets তৈরি করার সঠিক IAM permission আপনার আছে। এর সম্ভাব্য কারণ কী?

Correct: B. Why it is right

General purpose bucket er nam (default) globally unique: sob Region ar sob AWS account jure (PDF p. 271). dev er moto choto, common nam onek age-i keu niye feleche, tai create e error ashe, permission thik thakleo.

2026 er notun Account Regional Namespace opt-in feature; default global namespace e ei answer ekhono thik.

Why the other options are wrong

  • A. Root user lage na; je IAM user/role er s3:CreateBucket permission ache se-i bucket banate pare. Question e bola-i ache permission thik.

Keyword: "dev" nam e error + permission thik → nam globally unique, already taken

12·2U12-Q2Udemy quiz · sec 12 · Q2

You have enabled versioning in your S3 bucket which already contains a lot of files. Which version will the existing files have?

আপনি আপনার S3 bucket-এ versioning enable করেছেন, যেখানে আগে থেকেই অনেক file আছে। existing file-গুলোর version কী হবে?

Correct: D. Why it is right

Versioning enable korar age theke thaka file er version ID hoy null (PDF p. 282). Enable er por notun upload/overwrite e notun version ID ashe.

Hands-on e-o dekha geche: coffee.jpg, beach.jpg er version ID null.

Why the other options are wrong

  • A. S3 version ID 1, 2, 3 erokom number na; ar purono file kono number pay na, pay null.
  • B. 0 bole kono version ID S3 dey na; versioning er age er file er version null.
  • C. -1 S3 er kono version ID na; existing file er version null.

Keyword: existing files + versioning enabled later → version null

12·3U12-Q3Udemy quiz · sec 12 · Q3

You have updated an S3 bucket policy to allow IAM users to read/write files in the S3 bucket, but one of the users complain that he can't perform a PutObject API call. What is a possible cause for this?

আপনি IAM user-দের S3 bucket-এ file read/write করতে allow করার জন্য একটি S3 bucket policy update করেছেন, কিন্তু একজন user অভিযোগ করছে যে সে PutObject API call করতে পারছে না। এর সম্ভাব্য কারণ কী?

Correct: C. Why it is right

S3 access rule: IAM policy ALLOW ba resource (bucket) policy ALLOW korle hoy, kintu kono explicit DENY thakle DENY jite (PDF p. 274).

Bucket policy allow korche, tobu ekjon user PutObject parche na → tar attached IAM policy te explicit Deny ache.

Why the other options are wrong

  • A. Bucket policy bhul hole sob user-i parto na; ekhane shudhu ekjon user er problem, tai user er nijer policy te kichu ache.
  • B. Bucket policy already user ke allow korche; IAM permission na thakleo bucket policy er Allow-i jothesto. Tai 'permission nai' karon na.
  • D. PutObject er kono limit AWS Support diye tulte hoy na; eta permission er problem, service limit na.

Keyword: bucket policy allow kore + ekjon user parche na → IAM policy te explicit DENY

Instructor feedback (English)

B: Even if the user doesn't have permissions, in the question the S3 bucket is explicitly allowing the user and that's enough from a permission's perspective

C: Explicit DENY in an IAM Policy will take precedence over an S3 bucket policy.

12·4U12-Q4Udemy quiz · sec 12 · Q4

You want the content of an S3 bucket to be fully available in different AWS Regions. That will help your team perform data analysis at the lowest latency and cost possible. What S3 feature should you use?

আপনি চান একটি S3 bucket-এর content বিভিন্ন AWS Regions-এ পুরোপুরি available থাকুক। এতে আপনার team সম্ভাব্য সবচেয়ে কম latency ও cost-এ data analysis করতে পারবে। কোন S3 feature ব্যবহার করা উচিত?

Correct: D. Why it is right

S3 Replication (CRR) bucket er content asynchronously onno Region er bucket e copy kore (PDF p. 283). Tai protita Region e pura data thake, team kache theke lowest latency te analysis korte pare.

CRR use case: compliance, lower latency access, cross-account replication.

Why the other options are wrong

  • A. CloudFront edge location e cache kore, kintu bucket er pura content onno Region er bucket e copy kore na; analysis er jonno full data available hoy na.
  • B. Versioning shudhu overwrite/delete e purono version rakhe; onno Region e copy kore na (tobe replication er prerequisite).
  • C. Static Website Hosting bucket ke website hisebe serve kore; onno Region e data copy kore na.

Keyword: content fully available in different Regions → S3 Replication (CRR)

Instructor feedback (English)

A: Amazon CloudFront caches your data in different Edge Locations across the world, but it won't copy the content of your S3 bucket to a different AWS Region.

B: S3 Versioning allows you to keep different versions of a file in case of overwrites.

D: S3 Replication allows you to replicate data from an S3 bucket to another in the same/different AWS Region.

12·5U12-Q5Udemy quiz · sec 12 · Q5

You have 3 S3 buckets. One source bucket A, and two destination buckets B and C in different AWS Regions. You want to replicate objects from bucket A to both bucket B and C. How would you achieve this?

আপনার 3টি S3 bucket আছে। একটি source bucket A, এবং ভিন্ন ভিন্ন AWS Regions-এ দুটি destination bucket B এবং C। আপনি bucket A থেকে bucket B ও C দুটোতেই object replicate করতে চান। কীভাবে এটি করবেন?

Correct: A. Why it is right

S3 Replication e chaining nai: bucket 1 → 2 → 3 thakle bucket 1 er object bucket 3 e jabe na (PDF p. 284).

Tai A theke B ar C dui jaygay chaile source A te duita rule dao: A → B ar A → C.

Why the other options are wrong

  • B. B → C chain kaj kore na: A theke B te asha replica object B → C rule e replicate hoy na, tai C te A er object ashbe na.
  • C. Ek-i chaining problem: A → C er replica C → B diye abar replicate hoy na, B te A er object pouchabe na.

Keyword: A theke B ar C dutoi + chaining nai → A→B, A→C

Instructor feedback (English)

B: S3 Replication doesn't support "chaining" of replication.

C: S3 Replication doesn't support "chaining" of replication.

12·6U12-Q6Udemy quiz · sec 12 · Q6

Which of the following is NOT a Glacier Deep Archive retrieval mode?

নিচের কোনটি Glacier Deep Archive-এর retrieval mode নয় (NOT)?

Correct: A. Why it is right

Question NOT chacche. Glacier Deep Archive e retrieval mode shudhu duita: Standard (12 hours) ar Bulk (48 hours) (PDF p. 289).

Expedited (1-5 min) Deep Archive e nai; eta Glacier Flexible Retrieval er mode.

Why the other options are wrong

  • B. Standard (12 hours) Deep Archive er valid retrieval mode, tai 'NOT' er answer na.
  • C. Bulk (48 hours) Deep Archive er valid (sobcheye shosta) retrieval mode, tai 'NOT' er answer na.

Keyword: NOT + Deep Archive → Expedited nai (shudhu Standard 12 h, Bulk 48 h)

12·7U12-Q7Udemy quiz · sec 12 · Q7

Which of the following is NOT a Glacier Flexible retrieval mode?

নিচের কোনটি Glacier Flexible-এর retrieval mode নয় (NOT)?

Correct: A. Why it is right

Question NOT chacche. Glacier Flexible Retrieval er mode: Expedited (1-5 min), Standard (3-5 h), Bulk (5-12 h, free) (PDF p. 289).

'Instant' bole kono mode nai; millisecond access chaile alada class Glacier Instant Retrieval.

Why the other options are wrong

  • B. Expedited (1-5 minutes) Glacier Flexible er valid mode, tai 'NOT' er answer na.
  • C. Standard (3-5 hours) Glacier Flexible er valid mode.
  • D. Bulk (5-12 hours) Glacier Flexible er valid, free mode.

Keyword: NOT + Glacier Flexible → Instant bole mode nai (eta Glacier Instant Retrieval class)
