Lecture 1 + 2 (hands-on) · EBS Overview, EBS Hands On · PDF p. 95-98 (part p. 2-5)

EBS volume: network er USB stick

Shohoj kore: EBS holo ekta pen drive ja computer e shorashori dhokano na, network er tar diye lagano. Computer (EC2) noshto hole pen drive khule onno computer e lagano jay, data thik thake. Shorto: pen drive ta shudhu oi building (AZ) er computer e lagano jay.

EBS ki (PDF p. 95-96 (part p. 2-3))

  • EBS = Elastic Block Store. Ekta network drive ja instance chalu thakar somoy attach kora jay. Ager section e na jenei use korechi (root volume).
  • Instance terminate holeo data persist korte pare: notun instance baniye same volume mount korle data ferot.
  • CCP (Cloud Practitioner) level e: ek somoy shudhu ek instance e mount (exception: Multi-Attach, Lecture 9).
  • Ekta specific AZ e bandha.
  • Network drive (physical na): instance ar volume er moddhe network, tai ektu latency thakte pare.
  • Network drive bole druto detach kore onno instance e attach kora jay: failover e kaje lage.
  • us-east-1a er volume us-east-1b te attach hoy na. Onno AZ e nite hole age snapshot (Lecture 3).
  • Capacity age theke provision: koto GB ar koto IOPS (I/O operations per second). Je capacity provision korecho purotar bill. Pore capacity barano jay.

Lecture 7 · EC2 Instance Store · PDF p. 103-104 (part p. 10-11)

EC2 Instance Store: server er nijer fast disk, kintu temporary

Shohoj kore: EBS holo network diye lagano pen drive. Instance Store holo laptop er bhitorer SSD: onek druto, kintu laptop (host) bodlale ba noshto hole oi SSD er data sathe jay. Hotel room er table er moto: kaj chalakalin rakho, checkout (stop) korle sob porishkar.

Mul kotha (PDF p. 103 (part p. 10))

  • EBS = network drive, performance bhalo kintu "limited".
  • High-performance hardware disk lagle → EC2 Instance Store: physical server e shorashori lagano hard drive (kichu special instance type e thake).
  • Better I/O performance, bhalo throughput.
  • Instance stop (ba terminate) korle storage harabe → ephemeral. Long-term durable storage na.
  • Bhalo kaj: buffer / cache / scratch data / temporary content. Long-term er jonno EBS.
  • Underlying hardware fail korle data loss er risk.
  • Backup ar replication tomar dayitto.

Koto fast (PDF p. 104 (part p. 11))

  • Udaharon (mukhosto lagbe na): i3 family er instance store e random Read IOPS ~3.3 million, Write IOPS ~1.4 million (sobcheye boro size e).
  • EBS volume er IOPS er tulonay eta onek onek beshi (Lecture 8 er table dekho: EBS er max 256,000).
  • Exam: "very high performance, hardware attached volume" dekhle → local EC2 Instance Store.
