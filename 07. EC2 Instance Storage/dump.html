7·4D-Q252SAA-C03 dump · Q252

A company is migrating a Linux-based web server group to AWS. The web servers must access files in a shared file store for some content. The company must not make any changes to the application. What should a solutions architect do to meet these requirements?

একটি company একটি Linux-based web server group AWS-এ migrate করছে। কিছু content-এর জন্য web server-গুলোকে একটি shared file store-এর file access করতে হবে। company application-এ কোনো পরিবর্তন করতে পারবে না। এই requirement-গুলো পূরণ করতে একজন solutions architect-এর কী করা উচিত?

Correct: C. Why it is right

Linux web server group shared file store chay, app change chara. Amazon EFS NFS (POSIX) file system, onek Linux instance (multi-AZ) eksathe mount korte pare (PDF p. 113). App normal file path diye file pore, tai kono change lage na.

Why the other options are wrong

  • A. S3 object storage, file system na; app ke S3 API use korte change korte hobe.
  • B. CloudFront + S3 content delivery er jonno; server er shared file system na, app change lagbe.
  • D. gp3 EBS ek somoy ek instance e attach hoy (Multi-Attach shudhu io1/io2), sob web server share korte pare na.

Keyword: Linux web servers + shared file store + no changes to application → Amazon EFS

Dump explanation (English)

Create an Amazon Elastic File System (Amazon EFS) file system. Mount the EFS file system on all web servers. To meet the requirements of providing a shared file store for Linux-based web servers without making changes to the application, using an Amazon EFS file system is the best solution. Amazon EFS is a managed NFS file system service that provides shared access to files across multiple Linux-based instances, which makes it suitable for this use case. Amazon S3 is not ideal for this scenario since it is an object storage service and not a file system, and it requires additional tools or libraries to mount the S3 bucket as a filesystem. Amazon CloudFront can be used to improve content delivery performance but is not necessary for this requirement. Additionally, Amazon EBS volumes can only be mounted to one instance at a time, so it is not suitable for sharing files across multiple instances.
