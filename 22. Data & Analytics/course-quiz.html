22·1U22-Q1Udemy quiz · sec 22 · Q1

You would like to have a database that is efficient at performing analytical queries on large sets of columnar data. You would like to connect to this Data Warehouse using a reporting and dashboard tool such as Amazon QuickSight. Which AWS technology do you recommend?

আপনি এমন একটি database চান, যা columnar data-র বড় set-এর ওপর analytical query চালাতে efficient। আপনি Amazon QuickSight-এর মতো একটি reporting ও dashboard tool দিয়ে এই Data Warehouse-এ connect করতে চান। আপনি কোন AWS technology recommend করবেন?

Renamed: Amazon QuickSight -> Amazon Quick Sight (part of Amazon Quick) (the answer is the same).

Correct: C. Why it is right

Redshift holo AWS er OLAP data warehouse: data columnar hisabe rakhe ar parallel query engine diye boro dataset e analytical query druto chalay (PDF p. 534).

QuickSight / Tableau er moto BI tool Redshift er sathe directly integrate kore, tai dashboard er jonno eta-i fit.

Why the other options are wrong

  • A. RDS holo OLTP (transaction) er relational DB, row based; boro analytical / columnar query er data warehouse na.
  • B. S3 object storage, nije query engine na; S3 er data query korte Athena / Spectrum lage.
  • D. Neptune graph database (relationship, social network), columnar analytics warehouse na.

Keyword: analytical queries + columnar + Data Warehouse + QuickSight → Redshift

22·2U22-Q2Udemy quiz · sec 22 · Q2

You have a lot of log files stored in an S3 bucket that you want to perform a quick analysis, if possible Serverless, to filter the logs and find users that attempted to make an unauthorized action. Which AWS service allows you to do so?

একটি S3 bucket-এ আপনার অনেক log file store করা আছে, যেগুলোর ওপর আপনি একটি দ্রুত analysis করতে চান, সম্ভব হলে Serverless-ভাবে, যাতে log filter করে unauthorized action করার চেষ্টা করা user-দের খুঁজে বের করা যায়। কোন AWS service আপনাকে তা করতে দেয়?

Correct: D. Why it is right

Athena serverless query service: S3 e rakha file (log, CSV, JSON, Parquet) e directly standard SQL chalay, kono server ba database provision lage na, data move korte hoy na (PDF p. 531).

Course er hands-on e S3 access log e Athena diye 403 (unauthorized) request khoja hoyechilo: ei proshner hubohu scenario.

Why the other options are wrong

  • A. DynamoDB NoSQL database; S3 er log query korte age DynamoDB te load korte hobe, quick analysis na.
  • B. Redshift e cluster (ba serverless warehouse) + data load / Spectrum lage; quick serverless log analysis er jonno Athena shohoj.
  • C. S3 Glacier archive storage class; ekhane query engine nai, data restore korte o shomoy lage.

Keyword: log files in S3 + quick analysis + Serverless → Athena

22·3U22-Q3Udemy quiz · sec 22 · Q3

As a Solutions Architect, you have been instructed you to prepare a disaster recovery plan for a Redshift cluster. What should you do?

একজন Solutions Architect হিসেবে আপনাকে একটি Redshift cluster-এর জন্য একটি disaster recovery plan প্রস্তুত করতে নির্দেশ দেওয়া হয়েছে। আপনার কী করা উচিত?

Correct: B. Why it is right

Redshift DR er course pattern: automated snapshot on koro (point-in-time, incremental, S3 e), ar Redshift ke configure koro snapshot automatically onno AWS Region e copy korte. Disaster hole oi Region e copied snapshot theke notun cluster restore (PDF p. 536).

Why the other options are wrong

  • A. Multi-AZ (kichu cluster type e, RA3) shudhu ek Region er AZ failure dhake; puro Region down hole kaaj kore na, tai full DR plan na.
  • C. "Redshift Global cluster" bole kono feature nai (Aurora Global Database er sathe gulano distractor).

Keyword: disaster recovery plan for Redshift → automated snapshot + cross-region snapshot copy

22·4U22-Q4Udemy quiz · sec 22 · Q4

Which feature in Redshift forces all COPY and UNLOAD traffic moving between your cluster and data repositories through your VPCs?

Redshift-এর কোন feature আপনার cluster এবং data repository-গুলোর মধ্যে চলাচলকারী সব COPY ও UNLOAD traffic-কে আপনার VPC-র মধ্য দিয়ে যেতে বাধ্য করে?

Correct: A. Why it is right

Enhanced VPC Routing on korle Redshift er COPY / UNLOAD traffic (cluster ↔ S3 er moto data repository) internet diye na giye tomar VPC er moddhe diye jay (PDF p. 537).

Off thakle traffic internet diye jay.

Why the other options are wrong

  • B. "Improved VPC Routing" naam e kono Redshift feature nai; naam milano trap.
  • C. Redshift Spectrum S3 er data load na kore query kore; traffic routing er sathe somporko nai.

Keyword: COPY and UNLOAD traffic through your VPC → Enhanced VPC Routing

22·5U22-Q5Udemy quiz · sec 22 · Q5

You are running a gaming website that is using DynamoDB as its data store. Users have been asking for a search feature to find other gamers by name, with partial matches if possible. Which AWS technology do you recommend to implement this feature?

আপনি একটি gaming website চালাচ্ছেন, যা data store হিসেবে DynamoDB ব্যবহার করছে। user-রা নাম দিয়ে অন্য gamer-দের খুঁজে পেতে একটি search feature চাইছেন, সম্ভব হলে partial match-সহ। এই feature implement করতে আপনি কোন AWS technology recommend করবেন?

Correct: C. Why it is right

DynamoDB te query shudhu primary key ba index diye; naam er ongsho diye khoja (partial match) jay na. OpenSearch je kono field e search kore, partial match o (PDF p. 539).

Course pattern: DynamoDB table → DynamoDB Stream → Lambda → OpenSearch; app OpenSearch e search kore item ID pay, tarpor DynamoDB theke full item ane (PDF p. 540).

Why the other options are wrong

  • A. DynamoDB nije shudhu key / index diye query kore; free-text partial match search dite pare na (Scan kora slow + expensive).
  • B. Redshift analytics data warehouse; app er real-time name search er jonno na.
  • D. Neptune graph database (relationship query); text search / partial match er tool na.

Keyword: search feature + partial matches + DynamoDB → OpenSearch

22·6U22-Q6Udemy quiz · sec 22 · Q6

An AWS service allows you to create, run, and monitor ETL (extract, transform, and load) jobs in a few clicks.

একটি AWS service আপনাকে কয়েকটি click-এ ETL (extract, transform, and load) job তৈরি, চালানো ও monitor করতে দেয়।

Correct: A. Why it is right

AWS Glue fully serverless, managed ETL (extract, transform, load) service (PDF p. 548). Glue Studio GUI diye ETL job create, run ar monitor kora jay (PDF p. 551): "few clicks" er mane eta.

Why the other options are wrong

  • B. Redshift data warehouse (ETL er destination hote pare), ETL job banano / chalano service na.
  • C. RDS relational OLTP database; ETL job create / run kore na.
  • D. DynamoDB NoSQL database; ETL service na.

Keyword: create, run, and monitor ETL jobs → AWS Glue

22·7U22-Q7Udemy quiz · sec 22 · Q7

A company is using AWS to host its public websites and internal applications. Those different websites and applications generate a lot of logs and traces. There is a requirement to centrally store those logs and efficiently search and analyze those logs in real-time for detection of any errors and if there is a threat. Which AWS service can help them efficiently store and analyze logs?

একটি company তাদের public website ও internal application host করতে AWS ব্যবহার করছে। এই বিভিন্ন website ও application প্রচুর log ও trace তৈরি করে। এই log-গুলো centrally store করার এবং কোনো error ও threat আছে কিনা detect করতে real-time-এ efficiently search ও analyze করার requirement আছে। কোন AWS service তাদের efficiently log store ও analyze করতে সাহায্য করতে পারে?

Correct: B. Why it is right

OpenSearch log ar trace index kore, je kono field e druto search + analyze kore, ar OpenSearch Dashboards diye visualize kore (PDF p. 539). CloudWatch Logs / Firehose theke real time ba near real time e ingest kora jay (PDF p. 541-542).

Tai "centrally store + efficiently search + analyze real time (error / threat)" = OpenSearch.

Why the other options are wrong

  • A. S3 log store korte pare, kintu nije search / real-time analysis kore na; query er jonno alada service lage.
  • C. ElastiCache in-memory cache (Redis / Memcached); log store + search er jonno na.
  • D. QLDB immutable ledger database (ar ekhon end of support); log search / analytics tool na.

Keyword: centrally store logs + search and analyze in real-time → OpenSearch

22·8U22-Q8Udemy quiz · sec 22 · Q8

……………………….. makes it easy and cost-effective for data engineers and analysts to run applications built using open source big data frameworks such as Apache Spark, Hive, or Presto without having to operate or manage clusters.

……………………….. data engineer ও analyst-দের জন্য cluster operate বা manage না করেই Apache Spark, Hive, বা Presto-র মতো open source big data framework ব্যবহার করে তৈরি application চালানো সহজ ও cost-effective করে।

Correct: B. Why it is right

Amazon EMR (Elastic MapReduce) open-source big data framework Apache Spark, Hive, Presto (aro HBase, Flink) chalay; provisioning ar configuration EMR nije kore (PDF p. 543).

"Without having to operate or manage clusters" wording ta EMR Serverless (June 2022 GA, course e nai) er sathe mele; answer EMR-i.

Why the other options are wrong

  • A. Lambda event-driven function (max 15 min); Spark / Hive / Presto er moto big data framework chalay na.
  • C. Athena serverless SQL on S3 (Presto based), kintu Spark / Hive application chalanor platform na.
  • D. OpenSearch search / log analytics engine; Spark / Hive / Presto application chalay na.

Keyword: Apache Spark, Hive, Presto big data frameworks → EMR

22·9U22-Q9Udemy quiz · sec 22 · Q9

An e-commerce company has all its historical data such as orders, customers, revenues, and sales for the previous years hosted on a Redshift cluster. There is a requirement to generate some dashboards and reports indicating the revenues from the previous years and the total sales, so it will be easy to define the requirements for the next year. The DevOps team is assigned to find an AWS service that can help define those dashboards and have native integration with Redshift. Which AWS service is best suited?

একটি e-commerce company-র আগের বছরগুলোর order, customer, revenue ও sales-এর মতো সব historical data একটি Redshift cluster-এ hosted। আগের বছরগুলোর revenue এবং মোট sales দেখায় এমন কিছু dashboard ও report তৈরি করার requirement আছে, যাতে পরের বছরের requirement নির্ধারণ করা সহজ হয়। DevOps team-কে এমন একটি AWS service খুঁজে বের করার দায়িত্ব দেওয়া হয়েছে, যা এই dashboard-গুলো define করতে সাহায্য করতে পারে এবং Redshift-এর সাথে native integration আছে। কোন AWS service সবচেয়ে উপযুক্ত (best suited)?

Renamed: Amazon QuickSight -> Amazon Quick Sight (part of Amazon Quick) (the answer is the same).

Correct: C. Why it is right

QuickSight serverless, ML-powered BI service: interactive dashboard ar report banay (PDF p. 545). Redshift er sathe native integration ache (RDS, Aurora, Athena, S3 o) (PDF p. 546).

Ekhon naam Amazon Quick Sight (Amazon Quick er BI feature); kaaj ek-i.

Why the other options are wrong

  • A. OpenSearch search / log analytics (OpenSearch Dashboards shudhu OpenSearch data er jonno); Redshift business dashboard er tool na.
  • B. Athena S3 e serverless SQL chalay; dashboard / visualization banay na (QuickSight er data source hoy).
  • D. EMR big data processing cluster (Spark / Hadoop); BI dashboard tool na.

Keyword: dashboards and reports + native integration with Redshift → QuickSight

22·10U22-Q10Udemy quiz · sec 22 · Q10

Which AWS Glue feature allows you to save and track the data that has already been processed during a previous run of a Glue ETL job?

AWS Glue-এর কোন feature একটি Glue ETL job-এর আগের run-এ ইতিমধ্যে process হওয়া data save ও track করতে দেয়?

Correct: A. Why it is right

Glue Job Bookmarks previous run e kon data already process hoyeche sheta track kore, tai notun run e purono data abar process hoy na (PDF p. 551).

Why the other options are wrong

  • B. Glue Elastic Views SQL diye multiple data store jure view banato; processed data track kore na. Ar AWS bole eta April 2022 theke available na.
  • C. Glue Streaming ETL stream (KDS, Kafka, MSK) theke continuous ETL chalay; processed data er state rakha er feature na.
  • D. Glue DataBrew pre-built transformation diye data clean / normalize kore; previous run track kore na.

Keyword: track data already processed during a previous run → Glue Job Bookmarks

22·11U22-Q11Udemy quiz · sec 22 · Q11

You are a DevOps engineer in a machine learning company which 3 TB of JSON files stored in an S3 bucket. There’s a requirement to do some analytics on those files using Amazon Athena and you have been tasked to find a way to convert those files’ format from JSON to Apache Parquet. Which AWS service is best suited?

আপনি একটি machine learning company-র DevOps engineer, which 3 TB JSON file একটি S3 bucket-এ store করা আছে। Amazon Athena ব্যবহার করে এই file-গুলোর ওপর কিছু analytics করার requirement আছে, এবং আপনাকে এই file-গুলোর format JSON থেকে Apache Parquet-এ convert করার উপায় খুঁজে বের করার দায়িত্ব দেওয়া হয়েছে। কোন AWS service সবচেয়ে উপযুক্ত (best suited)?

Correct: D. Why it is right

Glue ETL job S3 er JSON / CSV pore Apache Parquet (columnar) e convert kore output bucket e rakhe (PDF p. 549). Parquet e Athena shudhu dorkari column scan kore, tai query sosta ar druto (PDF p. 532).

Why the other options are wrong

  • A. S3 Versioning object er purono version rakhe; file format convert kore na.
  • B. Kinesis Data Streams real-time streaming ingest; S3 e already rakha 3 TB file er format convert er tool na.
  • C. Amazon MSK managed Kafka streaming; JSON → Parquet conversion kore na.

Keyword: convert JSON to Apache Parquet for Athena → AWS Glue (ETL)

22·12U22-Q12Udemy quiz · sec 22 · Q12

You have an on-premises application that is used together with an on-premises Apache Kafka to receive a stream of clickstream events from multiple websites. You have been tasked to migrate this application as soon as possible without any code changes. You decided to host the application on an EC2 instance. What is the best option you recommend to migrate Apache Kafka?

আপনার একটি on-premises application আছে, যা একাধিক website থেকে clickstream event-এর একটি stream receive করতে একটি on-premises Apache Kafka-র সাথে ব্যবহৃত হয়। আপনাকে কোনো code change ছাড়াই যত দ্রুত সম্ভব এই application migrate করার দায়িত্ব দেওয়া হয়েছে। আপনি application-টি একটি EC2 instance-এ host করার সিদ্ধান্ত নিয়েছেন। Apache Kafka migrate করতে আপনি কোন option-টিকে সবচেয়ে ভালো (best) হিসেবে recommend করবেন?

Renamed: Kinesis Data Analytics -> Amazon Managed Service for Apache Flink (the answer is the same).

Correct: C. Why it is right

Amazon MSK = fully managed Apache Kafka AWS e (PDF p. 556). App Kafka API-i use korte thakbe, tai code change lage na; Kafka broker / Zookeeper MSK manage kore, migration druto.

Why the other options are wrong

  • A. Kinesis Data Streams Kafka er alternative, kintu API alada; app ke Kinesis SDK e rewrite korte hobe, "no code change" bhange.
  • B. Glue ETL service; Kafka broker hisabe kaaj kore na (Glue Streaming ETL Kafka theke porte pare matro).
  • D. Kinesis Data Analytics (ekhon Managed Service for Apache Flink) stream analyze kore, Kafka cluster replace kore na.

Keyword: on-premises Apache Kafka + without any code changes → Amazon MSK

22·13U22-Q13Udemy quiz · sec 22 · Q13

You have data stored in RDS, S3 buckets and you are using AWS Lake Formation as a data lake to collect, move and catalog data so you can do some analytics. You have a lot of big data and ML engineers in the company and you want to control access to part of the data as it might contain sensitive information. What can you use?

আপনার data RDS ও S3 bucket-এ store করা আছে, এবং আপনি data collect, move ও catalog করার জন্য data lake হিসেবে AWS Lake Formation ব্যবহার করছেন, যাতে কিছু analytics করতে পারেন। company-তে আপনার অনেক big data ও ML engineer আছেন, এবং আপনি data-র একটি অংশে access নিয়ন্ত্রণ করতে চান, কারণ এতে sensitive information থাকতে পারে। আপনি কী ব্যবহার করতে পারেন?

Correct: A. Why it is right

Lake Formation er boro shubidha: Fine-grained Access Control, row ar column-level security, ek jaygay (centralized) (PDF p. 552, 554). Sensitive column / row ke dekhbe sheta Lake Formation e set korle Athena, QuickSight, EMR shob service e kaaj kore.

Why the other options are wrong

  • B. Cognito app user er login / identity (user pool, identity pool); data lake er row / column permission dey na.
  • C. AWS Shield DDoS protection; data access control na.
  • D. S3 Object Lock WORM (delete / overwrite atkay); ke data porte parbe sheta control kore na.

Keyword: Lake Formation + control access to part of the data (sensitive) → Fine-grained Access Control
