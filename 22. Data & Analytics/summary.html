Hands-on: age query result location (S3 bucket) set. Tarpor database, tarpor S3 access log table (DDL AWS doc theke; LOCATION e bucket + prefix, sheshe trailing slash). Preview = 10 row. HTTP status count (404?), 403 filter = unauthorized attempt; server chara.

Weekly / occasional query → Athena (RDS, OpenSearch, EMR always-on cost). Cold data, SQL immediately, sosta → S3 Standard-IA + Athena (Glacier e age restore lage; "Redshift storage IA" bole kichu nai). Athena CSE-KMS encrypted Parquet o porte pare (S3 Select pare na).

Redshift: snapshot / DR, data load, Spectrum

Shohoj kore: Beshirbhag cluster ek AZ e, tai DR mane snapshot onno region e copy. Data dhokano: Firehose, S3 COPY, ba JDBC (boro batch). Ar S3 er data load na korei query = Spectrum.

Spectrum e cluster lagbei; tarpor cluster er cheye onek beshi processing power.

  • Snapshot: point-in-time, internally S3 e, incremental; restore notun cluster e. Automated: proti 8 h / 5 GB / schedule, retention 1-35 din. Manual: delete na kora porjonto. Kichu cluster e Multi-AZ mode o ache.
  • Enhanced VPC Routing: COPY / UNLOAD traffic internet er bodole puro VPC diye.
  • Spectrum: S3 e already thaka data load na kore query; Redshift table er sathe join kora jay.
Exam: Redshift DR → automated snapshot + cross-region auto copy (Multi-AZ shudhu AZ failure, "Redshift Global cluster" nai). COPY / UNLOAD VPC diye → Enhanced VPC Routing. Purono data S3 e sorao, daily report er sathe cross-reference → Spectrum (reload ba flat file export bhul). Clickstream Lambda diye enrich → S3 → Redshift, HA → Lambda + S3 + Spectrum (Spot HA na). Shudhu occasional SQL on S3 → Athena, Spectrum na (cluster er taka).

Shohoj kore: DynamoDB e item pete primary key (ba index) jante hoy. User "joh" likhle "John Smith" ber kora DynamoDB parbe na. OpenSearch je kono field search kore, partial match o. Tai main DB er pashe search engine hisabe boshe. Naam bodlano licensing er karone.

Exam: "Gamer ke name diye search, partial match" (DynamoDB app) → OpenSearch (DynamoDB, Redshift, Neptune na). "Website / app er log + trace centrally store, real time e search + analyze, error / threat" → OpenSearch. Real-time search + visualization, native → KDS → OpenSearch → QuickSight.

AWS Lake Formation

Shohoj kore: Company r data chhoriye ache (S3, RDS, Aurora, on-prem SQL / NoSQL). Data lake = analytics er jonno shob data ek jaygay (S3 e). Lake Formation mash er kaaj kichu din e kore. Ar shobcheye boro kotha: ke kon row / column dekhbe, ek jaygay thik koro.

Athena, QuickSight, S3 bucket policy, RDS user, Aurora user e alada alada security = mess. Lake Formation e ekbar.

  • Fully managed; discover, cleanse, transform, ingest. Collecting, cleansing, moving, cataloging automate; de-duplicate ML Transforms diye.
  • Structured + unstructured ek sathe. Out-of-the-box blueprints: S3, RDS, relational ar NoSQL DB theke migrate.

Exam traps

  • Cold data kintu "SQL immediately" dekhle S3 Standard-IA + Athena, Glacier na (age restore).
  • Redshift DR e "Multi-AZ" / "Global cluster" na, cross-region snapshot copy.
  • Flink er source dekhle KDS ba MSK; Firehose theke Flink pore na.
  • QuickSight share dekhle QuickSight user / group, IAM user / role na. SPICE shudhu import kora data te.
  • EMR cost dekhle primary + core On-Demand / Reserved, shudhu task Spot; idle node → managed scaling; daily kaaj → transient cluster.
  • "Least overhead" dekhle Glue / Athena / Firehose; EMR cluster, EC2 fleet na.
  • Glue + Lambda / DataBrew orchestrate dekhle Step Functions, Batch / EMR / SWF / Data Pipeline na.
  • MSK partition remove kora jay na; KDS shard split / merge hoy.
  • Dump key kichu jaygay bhul: Glue reprocess → Job Bookmarks; DynamoDB capacity na khaiye → Glue export connector; API message filter → SNS + SQS; RDS monthly report → read replica. Exam e logically thik ta dao.

Number mone rakho

  • Athena $5 / TB scanned; file > 128 MB bhalo; partition path year=/month=/day=.
  • Redshift onno warehouse er cheye 10x, petabyte; automated snapshot proti 8 h ba 5 GB ba schedule; retention 1-35 din; columnar block 1 MB (course e nai).
  • EMR Reserved min 1 bochor.
  • KDS message 1 MB; MSK default 1 MB, configure kore beshi (jemon 10 MB). MSK multi-AZ 3 porjonto; retention unlimited (EBS), 1 bochor er beshi o.
  • Firehose S3 e near real time, lowest frequency 1 minute.
  • Lambda max 15 min (2000 × 3 s = 100 min → EC2).
  • Naam: Kinesis Data Analytics (ajke: Managed Service for Apache Flink; KDA for SQL 27 Jan 2026 theke bondho), Kinesis Data Firehose (ajke: Amazon Data Firehose), ElasticSearch (ajke: OpenSearch), QuickSight (ajke: Amazon Quick Sight), Glue Elastic Views (ajke: nai), Data Pipeline ar S3 / Glacier Select (ajke: notun customer pay na).
