Correct: D. Why it is right

Hundreds of TB, kintu line shudhu 1 Gbps: course er table e 100 TB 1 Gbps e 12 din lage (PDF p. 354). Rule of thumb: network e 1 soptaho er beshi lagle → Snowball.

Ar "processing it while in transit" → Snowball Edge e compute ache (104 vCPU, EC2 instance ba Lambda chalano jay), tai data load korar shomoy-i preprocess kora jay (PDF p. 353, 356).

Aajker update: Nov 7, 2025 theke Snowball Edge notun customer der jonno available na (existing ra use korte pare); notun customer ke AWS DataSync (online) ba AWS Data Transfer Terminal bole. Exam/course answer ekhono Snowball Edge.

Why the other options are wrong

  • A. 1 Gbps e hundreds of TB pathate soptaho lage, ar transit e process korar kono upay nai.
  • B. Snowcone khub choto device (DataSync agent pre-installed), hundreds of TB er jonno na; ar eta 2024 e discontinued.
  • C. Data/Database Migration Service database migrate kore, file data ship ba transit e process kore na.

Keyword: hundreds of TB + 1 Gbps + process while in transit → Snowball Edge

Instructor feedback (English)

D: Snowball Edge is the right answer as it comes with computing capabilities and allows you to pre-process the data while it's being moved into Snowball.

16·2U16-Q2Udemy quiz · sec 16 · Q2

You want to expose virtually infinite storage for your tape backups. You want to keep the same software you're using and want an iSCSI compatible interface. What do you use?

আপনি আপনার tape backup-এর জন্য কার্যত অসীম storage দিতে চান। আপনি বর্তমানে যে software ব্যবহার করছেন সেটিই রাখতে চান এবং একটি iSCSI compatible interface চান। আপনি কী ব্যবহার করবেন?

Correct: B. Why it is right

Tape Gateway = Virtual Tape Library (VTL), backed by S3 ar Glacier (PDF p. 369).

  • Backup software same thake: leading backup vendor der sathe kaj kore, existing tape process cholte thake.
  • Interface iSCSI (VTL), tai backup server bhabe normal tape library.
  • Pichone S3/Glacier, tai storage virtually infinite.

Why the other options are wrong

  • A. Snowball ekbar data physically ship kore migrate kore; tape backup software er jonno ongoing iSCSI VTL interface dey na.
  • C. Volume Gateway iSCSI block volume (disk) dey, tape library na; backup software tape hishebe dekhte pabe na.
  • D. S3 File Gateway NFS/SMB file share dey, iSCSI na, tape interface o na.

Keyword: tape backups + same software + iSCSI → Tape Gateway

You have a large dataset stored in S3 that you want to access from on-premises servers using the NFS or SMB protocol. Also, you want to authenticate access to these files through on-premises Microsoft AD. What would you use?

আপনার S3-এ store করা একটি বড় dataset আছে, যেটি আপনি NFS বা SMB protocol ব্যবহার করে on-premises server থেকে access করতে চান। এছাড়া আপনি on-premises Microsoft AD-এর মাধ্যমে এই file-গুলোর access authenticate করতে চান। আপনি কী ব্যবহার করবেন?

Keyword: S3 dataset on-prem theke NFS / SMB + on-prem AD → S3 File Gateway

Tai "distributed POSIX + HPC + genomics + millions of IOPS" → FSx for Lustre.

Why the other options are wrong

  • A. EFS Max I/O mode beshi throughput ar parallelism dey kintu latency beshi; eta general Linux share, HPC er jonno na.
  • C. S3 object storage, POSIX compliant file system na; EC2 te "mount" kore HPC file system hishebe chalano jay na.
  • D. Instance Store onek IOPS dey, kintu eta ek instance er physical disk; distributed/shared file system na, ar instance stop hole data jay.

16·9U16-Q9Udemy quiz · sec 16 · Q9

Which of the following protocols is NOT supported by AWS Transfer Family?

নিচের কোন protocol AWS Transfer Family support করে না (NOT supported)?

Correct: C. Why it is right

AWS Transfer Family S3 ba EFS e file in/out kore FTP protocol family diye: FTP, FTPS (FTP over SSL), SFTP (Secure FTP) (PDF p. 371).

TLS nije kono file transfer protocol na, eta encryption layer (FTPS er bhitore use hoy). Tai list e TLS-i "NOT supported".

Aajker update: Transfer Family e ekhon AS2 o ache, kintu TLS alada protocol hishebe na; answer same.

Why the other options are wrong

  • A. FTP supported (unencrypted, Transfer Family e shudhu VPC er bhitore).
  • B. FTPS (FTP over SSL) supported, encrypted in flight.
  • D. SFTP (Secure File Transfer Protocol) supported, encrypted in flight.

Keyword: Transfer Family NOT supported → FTP/FTPS/SFTP ache, TLS na

Instructor feedback (English)

C: AWS Transfer Family is a managed service for file transfers into and out of S3 or EFS using the FTP protocol, thus TLS is not supported.

You have on-premises sensitive files and documents that you want to regularly synchronize to AWS to keep another copy. Which AWS service can help you with that?

Correct: C. Why it is right

AWS DataSync on-premises (NFS, SMB, HDFS) theke AWS (S3, EFS, FSx) e data sync kore; task schedule kora jay: hourly, daily, weekly (PDF p. 373).

"Regularly synchronize" + "another copy" = scheduled sync. File permission ar metadata o preserve hoy, transfer TLS diye encrypted.

Why the other options are wrong

  • A. DMS database migrate/replicate kore; files ar documents er jonno na.
  • B. EFS nije ekta file system (destination hote pare), kintu on-prem theke sync korar service na.

Keyword: on-prem files / documents + regularly synchronize → DataSync

Instructor feedback (English)

A: AWS Database Migration Service (AWS DMS) helps you migrate databases to AWS quickly and securely.

B: Amazon EFS provides a simple, serverless, set-and-forget elastic file system for use with AWS and on-premises resources.
