30·1U30-Q1Udemy quiz · sec 30 · Q1

As part of your Disaster Recovery strategy, you would like to make sure your entire infrastructure is code (IaC) so that you can easily re-deploy it in any AWS region. Which AWS service do you recommend?

Correct: D. Why it is right

CloudFormation holo AWS er Infrastructure as Code (IaC) service: declarative template e bolo ki ki resource lagbe, CloudFormation sheta thik order e create kore (PDF p. 828-829).

Template ache mane jekono region e same infrastructure abar destroy ar re-create kora jay on the fly (PDF p. 830), DR er jonno perfect.

Why the other options are wrong

  • A. CodePipeline holo CI/CD release pipeline (build, test, deploy automate kore); infrastructure ke code hishebe define kore na.
  • B. Beanstalk web application deploy korar developer-centric managed platform; puro infrastructure IaC hishebe model kore na.
  • C. CodeDeploy shudhu application code EC2/Lambda/on-prem e deploy kore; infrastructure create kore na.

Keyword: entire infrastructure is code (IaC) + re-deploy in any region → CloudFormation

Instructor feedback (English)

A: AWS CodePipeline is a fully managed continuous delivery (CD) service that helps you automate your release pipeline for fast and reliable application and infrastructure updates. It automates the build, test, and deploy phases of your release process every time there is a code change.

B: AWS Elastic Beanstalk is an easy-to-use service for deploying and scaling web applications and services developed with Java, .NET, PHP, Node.js, Python, Ruby, Go, and Docker. It automatically handles the deployment, from capacity provisioning, load balancing, auto-scaling to application health monitoring.

C: AWS CodeDeploy is a fully managed deployment service that automates software deployments to a variety of computing services such as EC2, Fargate, Lambda, and your on-premises servers.

D: AWS CloudFormation is the de-facto service in AWS for infrastructure as code (IaC). It enables you to create and provision AWS infrastructure deployments predictably and repeatedly.

Which AWS service allows you to send marketing SMS and push notifications to a large number of customers with personalized messages?

⚠ Outdated: Amazon Pinpoint 30 Oct 2026 e end of support (20 May 2025 theke new customer bondho). SMS/push/OTP API gulo ekhon AWS End User Messaging e, email er jonno Amazon SES. Course/exam er answer ekhono Pinpoint. source

Correct: B. Why it is right

Amazon Pinpoint holo scalable 2-way marketing communication service: email, SMS, push, voice, in-app (PDF p. 834).

  • Customer segment kore personalized message pathano jay.
  • Message template, delivery schedule, targeted segment, full campaign banano jay; SNS/SES e eshob nije manage korte hoy.

Note (today): Pinpoint 30 Oct 2026 e end of support; SMS/push er API ekhon AWS End User Messaging e, email SES e. Kintu course/exam answer ekhono Pinpoint.

Why the other options are wrong

  • A. SNS notification pathay, kintu personalized marketing campaign, segment, template er feature nai; prottek message er audience/content nije manage korte hoy.
  • C. SES shudhu email service; SMS ba push notification pathay na.
  • D. Lambda compute service; nijei SMS/push campaign pathanor service na.

Keyword: marketing SMS + push + personalized messages → Amazon Pinpoint

30·3U30-Q3Udemy quiz · sec 30 · Q3

What is the most secure way to connect to an EC2 instance without exposing the SSH port 22?

Correct: A. Why it is right

SSM Session Manager EC2 ar on-prem server e secure shell dey SSM Agent ar IAM permission diye (PDF p. 835).

  • SSH access, bastion host, SSH key kichui lage na.
  • Port 22 open korte hoy na → better security.
  • Session log S3 ba CloudWatch Logs e pathano jay.

Why the other options are wrong

  • B. Site-to-Site VPN on-prem network ke VPC er shathe jore; tarpor o instance e dhukte SSH (port 22) lagbe.
  • C. Client VPN user ke VPC te dhokay, kintu instance e login korte abar SSH port 22 open rakhte hobe.
  • D. Bastion host nijei SSH (port 22) diye kaj kore, ar ekta extra instance manage korte hoy; less secure.

Keyword: most secure + without exposing SSH port 22 → SSM Session Manager

30·4U30-Q4Udemy quiz · sec 30 · Q4

Which AWS service allows you to run and schedule hundreds of thousands of computing jobs on AWS such as big data and complex analytics jobs?

Correct: C. Why it is right

AWS Batch fully managed batch processing: 100,000s computing batch job efficiently chalay (PDF p. 848).

  • Batch job = start ar end ache emon job.
  • Batch nije EC2 ba Spot instance launch kore, right amount of compute/memory dey.
  • Tumi shudhu job submit ba schedule koro, baki Batch kore.

Why the other options are wrong

  • A. "AWS Simple Batch Service" namer kono AWS service nai; eta distractor.
  • B. EC2 shudhu virtual server; job scheduling, queue, scaling nije manage korte hobe, onek ops overhead.
  • D. Lambda er time limit (15 min), limited runtime ar disk ache; boro long-running batch/analytics job er jonno Batch better (PDF p. 850).

Keyword: run and schedule hundreds of thousands of computing jobs → AWS Batch

30·5U30-Q5Udemy quiz · sec 30 · Q5

The company you are working on is using Salesforce and Slack internally. For archival and some analytics requirements, you have been tasked to transfer the data in both Salesforce and Slack to AWS in an S3 bucket. Which AWS service is best suited for this scenario?

Correct: A. Why it is right

Amazon AppFlow fully managed integration service, SaaS application ar AWS er moddhe data securely transfer kore (PDF p. 851).

  • Source: Salesforce, SAP, Zendesk, Slack, ServiceNow.
  • Destination: S3, Redshift, Snowflake etc.
  • Schedule, event ba on-demand e chole; nije integration code likhte hoy na.

Why the other options are wrong

  • B. DataSync on-prem/other cloud storage (NFS, SMB, HDFS, S3 API) theke AWS storage e data move kore; Salesforce/Slack er moto SaaS app theke na.
  • C. DMS database migrate kore (source DB → target DB); SaaS app er data S3 e ane na.
  • D. Application Migration Service (MGN) on-prem server lift-and-shift kore AWS e ane; SaaS data transfer kore na.

Keyword: Salesforce + Slack data → S3 → Amazon AppFlow
