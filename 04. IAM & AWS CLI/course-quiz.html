4·1U04-Q1Udemy quiz · sec 04 · Q1

What is a proper definition of an IAM Role?

IAM Role-এর সঠিক definition কোনটি?

Correct: C. Why it is right

IAM Role holo ekta IAM identity, user er moto permission thake, kintu eta physical manush use kore na - AWS service (jemon EC2 instance, Lambda function) use kore tomar hoye AWS e action nite (PDF p. 37).

Common role: EC2 Instance Role, Lambda Function Role, CloudFormation role.

Why the other options are wrong

  • A. Eta user ar group er relation (ek user multiple group e thakte pare); role er definition na.
  • B. Password policy holo account setting (min length, expiry, reuse prevent); role er sathe somporko nai.
  • D. Eta user e attach kora permission/policy er bornona; role holo alada identity ja AWS service use kore.

Keyword: used by an AWS service + set of permissions → IAM Role

Instructor feedback (English)

A: IAM Users can belong to multiple User Groups, but it's not the definition of an IAM Role.

B: IAM Roles are not a password policy.

C: Some AWS services need to perform actions on your behalf. To do so, you assign permissions to AWS services with IAM Roles.

D: IAM Roles can not be assigned to IAM Users.

4·2U04-Q2Udemy quiz · sec 04 · Q2

Which of the following is an IAM Security Tool?

নিচের কোনটি একটি IAM Security Tool?

Correct: A. Why it is right

Course e duita IAM Security Tool (PDF p. 38):

  • IAM Credentials Report (account-level): sob user er list ar tader credential (password, MFA, access key) er status.
  • IAM Access Advisor (user-level): user ke kon service er permission deya ache ar shesh kobe use koreche.

Why the other options are wrong

  • B. IAM Root Account Manager bole kono tool nai.
  • C. IAM Services Report bole kichu nai; asol ta holo Credentials Report.
  • D. IAM Security Advisor nai; asol naam IAM Access Advisor - naam mil diye trap.

Keyword: IAM Security Tool → Credentials Report (ar Access Advisor)

Instructor feedback (English)

A: IAM Credentials report lists all your AWS Account's IAM Users and the status of their various credentials.

B: There's no such AWS service.

C: There's no such AWS service.

D: There's no such AWS service.

4·3U04-Q3Udemy quiz · sec 04 · Q3

Which answer is INCORRECT regarding IAM Users?

IAM Users সম্পর্কে কোন উত্তরটি ভুল (INCORRECT)?

Correct: D. Why it is right

Question ta INCORRECT statement chay. IAM user nijer credential diye AWS e dhoke: console e username + password, CLI/SDK te nijer access keys (PDF p. 33). Root account er credential kokhono use/share kora jabe na (PDF p. 39).

Baki tin ta statement sotti, tai D-i answer.

Why the other options are wrong

  • A. Sotti statement: ek user multiple group e thakte pare (jemon Charles: Developers + Audit Team, PDF p. 25).
  • B. Sotti statement: user er group e thakar badhyobadhokota nai (Fred kono group e nai, PDF p. 25).
  • C. Sotti statement: policy sorasori user e attach kora jay, ba inline policy deya jay (PDF p. 27).

Keyword: INCORRECT → IAM user root credentials use kore na, nijer credential use kore

Instructor feedback (English)

D: IAM Users access AWS services using their own credentials (username & password or Access Keys).

4·4U04-Q4Udemy quiz · sec 04 · Q4

Which of the following is an IAM best practice?

নিচের কোনটি একটি IAM best practice?

Correct: B. Why it is right

IAM best practice (PDF p. 39): root account use korbe na, shudhu account setup er jonno. Daily kaj er jonno nijer IAM user (admin) use koro.

Sathe: one physical user = one IAM user, credential share na, MFA on.

Why the other options are wrong

  • A. Ulta: one physical user = one AWS user. Ek manusher jonno onek user banale audit ar management kothin hoy.
  • C. Credential kokhono share korbe na; colleague er jonno alada IAM user banao.
  • D. Ulta: MFA use ar enforce kora best practice; password churi holeo account safe thake.

Keyword: IAM best practice → root user use na

Instructor feedback (English)

A: This is not an IAM best practice, you should create one IAM User per physical person.

B: Use the root account only to create your first IAM User and a few account/service management tasks. For everyday tasks, use an IAM User.

C: This is not an IAM best practice, never share your AWS account credentials (password or Access Keys) with others.

D: This is not an IAM best practice, you should enable Multi-Factor Authentication (MFA) for all AWS accounts and IAM Users to ensure maximum security.

4·5U04-Q5Udemy quiz · sec 04 · Q5

What are IAM Policies?

IAM Policies কী?

Correct: B. Why it is right

IAM Policy holo JSON document ja permission define kore - kon action, kon resource e Allow/Deny (PDF p. 26, 28).

Policy attach kora jay users, groups ar roles e. Group e dile group er sob user inherit kore (PDF p. 27).

Why the other options are wrong

  • A. IAM policy account-to-account interaction define kore na; eta kono identity ke ki permission ache ta bole.
  • C. Eta password policy (min length, character type, expiry) - IAM policy na, alada account setting.
  • D. IAM policy customer-AWS somporko bole na; eta permission er JSON document.

Keyword: JSON documents + set of permissions → IAM Policies

Instructor feedback (English)

C: This is a password policy, not an IAM Policy.

4·6U04-Q6Udemy quiz · sec 04 · Q6

Which principle should you apply regarding IAM Permissions?

IAM Permissions-এর ক্ষেত্রে আপনার কোন principle apply করা উচিত?

Correct: C. Why it is right

AWS e least privilege principle: user er jotota dorkar tar beshi permission dibe na (PDF p. 26).

Access Advisor diye dekhte paro kon permission use hoy na, tarpor komiye dao.

Why the other options are wrong

  • A. Ulta: most privilege dile bhul ba hack hole damage onek boro hoy.
  • B. Chaile-i permission deya thik na; shudhu kaj er jonno ja lagbe tai dao.
  • D. IAM policy diye root account er permission komano jay na; ar eta kono permission principle o na - principle holo least privilege.

Keyword: principle for IAM Permissions → least privilege

Instructor feedback (English)

A: It's a bad practice to grant maximum privileges to all users.

B: You shouldn't grant permissions to your employees unless it's relevant to their work.

C: That's right! Don't give more permissions than the user needs.

D: You can not restrict root account permissions.

4·7U04-Q7Udemy quiz · sec 04 · Q7

What should you do to increase your root account security?

আপনার root account-এর security বাড়াতে আপনার কী করা উচিত?

Correct: D. Why it is right

MFA = password (ja tumi jano) + security device (ja tomar kache ache) (PDF p. 30). Password churi/hack holeo device chara login hobe na, tai root account safe thake.

Course bole: root account ar IAM users duto-i MFA diye protect koro.

Why the other options are wrong

  • A. Root account e by default sob permission thake, eta remove kora jay na.
  • B. Shudhu CLI use korle root security bare na; CLI o access key diye kaj kore, ar root access key rakha-i uchit na.
  • C. Ulta: root dia daily kaj bad practice; IAM user banao ar root shudhu setup e use koro.

Keyword: increase root account security → Enable MFA

Instructor feedback (English)

A: You can not remove permissions from the root account, it has all permissions by default.

B: This won't help with your root account security.

C: This is a bad practice. You should access your AWS account using IAM Users.

D: When you enable MFA, this adds another layer of security. Even if your password is stolen, lost, or hacked your account is not compromised.

4·8U04-Q8Udemy quiz · sec 04 · Q8

IAM User Groups can contain IAM Users and other User Groups.

IAM User Groups-এর মধ্যে IAM Users এবং অন্য User Groups থাকতে পারে।

Correct: B. Why it is right

False. Groups only contain users, not other groups (PDF p. 25). IAM e nested group nai.

Tobe ek user ekadhik group e thakte pare.

Why the other options are wrong

  • A. Group er bhitor group rakha jay na; group e shudhu IAM users thake.

Keyword: Users and other User Groups → group e shudhu users → False

Instructor feedback (English)

A: IAM User Groups can not be part of other User Groups.

B: IAM User Groups can contain only IAM Users.

4·9U04-Q9Udemy quiz · sec 04 · Q9

An IAM policy consists of one or more statements. A statement in an IAM Policy consists of the following, EXCEPT:

একটি IAM policy এক বা একাধিক statement নিয়ে গঠিত। একটি IAM Policy-র statement নিচেরগুলো নিয়ে গঠিত, তবে এটি বাদে (EXCEPT):

Correct: C. Why it is right

IAM policy structure (PDF p. 28): policy level e Version, Id (optional), Statement. Protita Statement e: Sid, Effect, Principal, Action, Resource, Condition.

Tai Version statement er part na, puro policy document er part ("2012-10-17").

Why the other options are wrong

  • A. Effect (Allow/Deny) statement er part.
  • B. Principal (kon account/user/role er upor apply) statement er part.
  • D. Action (kon API call allow/deny) statement er part.
  • E. Resource (kon resource e action apply) statement er part.

Keyword: statement er part EXCEPT → Version (eta policy level e)

Instructor feedback (English)

C: A statement in an IAM Policy consists of Sid, Effect, Principal, Action, Resource, and Condition. Version is part of the IAM Policy itself, not the statement.
