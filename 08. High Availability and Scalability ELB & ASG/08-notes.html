  • Pichone VPC er route table update hoy (advanced networking).

Exam e ki mone rakhbo

Scaling ar High Availability

  • Instance boro = vertical, scale up (r4.large → r4.4xlarge, t2.nano → u-12tb1.metal) (U08-Q1, S3-Q52). Instance sonkhya = horizontal, scale out/in (U08-Q2).
  • Vertical: DB, RDS, ElastiCache, hardware limit. Horizontal: distributed web app, ASG + LB.
  • HA = kompokkhe 2 AZ; passive (RDS Multi-AZ) ba active (horizontal).
  • Spike e app tier slow, architecture bodlano jabe na → ASG + ALB horizontal (S6-Q1). Elastic web tier → ELB + EC2 + ASG (B6-Q22). HA website → Multi-AZ + ELB + ASG (B5-Q4, B4-Q14).
  • "Ek AZ gele-o N ta": sobcheye boro AZ bad diye baki ≥ N, tarpor sobcheye kom mot. 4 lagbe → 3 AZ × 2 (S2-Q31, B4-Q35). 6 lagbe → 3+3+3 ba 6+6+0 (B4-Q36). Ek Region er duita AZ e bhag (B3-Q29). Min 4 = 2 AZ × 2, max 6 (S5-Q61).

ELB basics ar health check

  • ELB = managed; dey static DNS name, static IP na (U08-Q3). Single access point, SSL termination, stickiness, multi-AZ, public/private alada.
  • Integration: EC2, ASG, ECS, ACM, CloudWatch, Route 53, WAF, Global Accelerator.
  • Health check: port + route (/health), 200 na = unhealthy. Crash kora instance e user na jak → health check (U08-Q6).
  • Health check fail → ELB shudhu traffic bondho; terminate/replace/quarantine kore na (B1-Q1, B1-Q56).
  • ALB health check = HTTP/HTTPS; NLB = TCP/HTTP/HTTPS; ICMP/FTP na (B5-Q60, U08-Q20).
  • Sob target unhealthy, IP diye site khole → EC2 SG ALB SG allow kore na ba health check route bhul (S5-Q26, B5-Q54).
  • EC2 te shudhu LB theke → EC2 SG source = LB er security group, CIDR na (S4-Q52).
  • ELB Regional: onek AZ thik, onek Region na (S1-Q57). AZ LB te add na korle traffic pay na (B5-Q56). ELB er kaj = ek/onek AZ e traffic bhag (B2-Q5).
  • CLB deprecated, exam theke bad; purono question e concept same.

ALB

  • Layer 7: HTTP, HTTPS, WebSocket, HTTP/2; TCP na (U08-Q8). HTTP → HTTPS redirect LB e (U08-Q21).
  • Routing: path, hostname, query string, header (+ method, source IP); geography na (U08-Q9). Path → S1-Q48; content-based → ALB (S2-Q9); host + path → ALB (S4-Q26, S5-Q1).
  • Target: EC2 (ASG), ECS tasks, Lambda, private IP; NLB na (U08-Q10). Health check TG level e. Onek TG.
  • Microservice, container, ECS dynamic port mapping → ALB. CLB hole app proti ekta CLB.
  • Client IP → X-Forwarded-For (Port, Proto alada) (U08-Q5). ALB connection terminate kore, EC2 dekhe LB private IP.
  • Listener rule: condition (host, path, method, source IP, query, header) → action (forward, redirect, fixed response); priority 1 highest ... 50,000; default rule.

NLB

  • Layer 4: TCP, UDP, TLS; millions of req/s, ultra-low latency (U08-Q7, S1-Q7). UDP dekhle NLB.
  • AZ proti 1 static IP, Elastic IP dewa jay → whitelist / compliance (U08-Q11, S4-Q9: NLB + ASG). ALB e EIP na.
  • Target: EC2, private IP, ALB (NLB → ALB = static IP + HTTP rules). Instance ID target → primary ENI er primary private IP (S3-Q13).
  • Health check TCP, HTTP, HTTPS: TCP theke HTTP te jete shudhu health check bodlao (U08-Q20).
  • NLB SG ke EC2 SG e allow na korle targets unhealthy (hands-on).

GWLB

  • Layer 3, IP packet; 3rd party firewall, IDS/IPS, deep packet inspection; transparent gateway + load balancer.
  • GENEVE port 6081 → GWLB. Target: EC2, private IP. Route table update hoy.

Sticky sessions

  • Ek client → ek instance, cookie diye; CLB, ALB, NLB. Session/login harabe na; kufol imbalance.
  • Bar bar re-login → stickiness nai (U08-Q4). CLB session bind → sticky sessions (B6-Q51).
  • Reserved: AWSALB, AWSALBAPP, AWSALBTG; custom naam (APPUSERC) thik (U08-Q12). Duration cookie: AWSALB (ALB), AWSELB (CLB). Duration 1 s - 7 din.

Cross-zone

  • ALB: default on, free (TG level e off). NLB/GWLB: default off, on korle $. CLB: off, on korle free (S1-Q4).
  • AZ e instance asoman, ek AZ chape → enable cross-zone (U08-Q13, B6-Q18, B3-Q25).
  • 1 + 4 instance: on → 20% kore; off → 50% ar 12.5% kore (S3-Q14). Off = AZ proti shoman, tarpor AZ er bhitore bhag.

SSL/TLS, SNI

  • In-flight encryption; LB e SSL termination, pichone VPC te HTTP. X.509 cert, ACM (ba upload/import; IAM recommended na).
  • HTTPS listener: default cert lagbe, optional cert list, security policy (legacy client).
  • Ek listener e onek cert / onek hostname HTTPS → SNI (U08-Q14, U08-Q15, S4-Q40). SNI: ALB, NLB, CloudFront; CLB na (CLB = 1 cert, onek CLB).
  • Backend e o encrypted → HTTPS / SSL (B6-Q15).

Connection Draining / Deregistration Delay

  • CLB = Connection Draining; ALB/NLB = Deregistration Delay. 1-3600 s, default 300, 0 = off.
  • In-flight request drop → draining, idle timeout na (S3-Q53). 10 minute er request → delay > 10 min (S2-Q50). Chhoto request → kom value; lomba → beshi.

ASG basics

  • Scale out/in, min/desired/max, LB e auto register, unhealthy re-create, free (shudhu EC2 er dam).
  • Desired = max = 3 → alarm e kichu hoy na (U08-Q16). Max 20 e atke ba On-Demand limit (B3-Q10).
  • Benefit: fault tolerance, availability, cost; encryption na (B5-Q38).
  • ASG AZ jure, Region na; delete = instance terminate; data copy hoy na (S5-Q50).
  • Single monolith, AZ failure recover, shosta → ASG 1/1/1, 2 AZ + EIP user data + instance role (S2-Q62, B1-Q61).
  • HA + cost → min 2 + RI min capacity er jonno (S4-Q49). 80 steady → 80 RI + ASG launch template On-Demand + Spot (S2-Q33). Standard RI ASG er instance e-o lage (B1-Q53; key bhul: thik shudhu C, E).
  • DR onno Region → AMI copy + oi Region er ASG te notun AMI ID; "same AMI sob Region e" best practice na (B1-Q37, B4-Q54, B2-Q21).
  • Existing instance attach: running, AMI ache, onno ASG te na, same AZ (B5-Q2).

ASG health check

  • Default EC2 health check; ELB health check nije on. On thakle LB-unhealthy → ASG terminate + replace (U08-Q17, S5-Q65).
  • ALB soray kintu ASG replace kore na → ASG EC2 check, ALB ALB check (S1-Q1).
  • ASG terminate korche na → grace period baki, Impaired, ba ELB fail kintu EC2 check type (S5-Q18).
  • Rebalancing: age launch, pore terminate; unhealthy: age terminate, pore launch (S1-Q56).
  • Patch er somoy replace na hok → Standby (+ key: Launch suspend) (S1-Q32).
  • Default termination: beshi instance wala AZ → oldest launch template/config (S4-Q16).

Launch Template

  • Thake: AMI, instance type, user data, EBS, SG, key pair, IAM role, network/subnet, LB info. ASG e: min/max/initial, scaling policy.
  • Launch Configuration deprecated, edit hoy na → notun AMI/type e notun LC (ekhon notun template version) (B3-Q3, B4-Q44, S1-Q6, S4-Q22).
  • On-Demand + Spot, onek instance type → shudhu launch template (S2-Q7, S2-Q48).
  • Purono LC trivia: CLI diye LC → detailed monitoring default (S3-Q15); VPC ba LC dedicated → instance dedicated (S3-Q21).

Scaling policies ar cooldown

  • Target tracking: "~X rakho" (CPU 40/50%, ~1000 connection) (U08-Q19, S1-Q30). Nije alarm banay (AlarmHigh/AlarmLow).
  • Simple/Step: alarm threshold e +/- (CPU > 70% → +2; < 30% → -1).
  • Scheduled: jana shomoy/event age theke (6 pm, maser shesh din desired 10, Thanksgiving) (S1-Q21, S1-Q45, S1-Q9). Lifecycle hook scale kore na.
  • Predictive: history theke ML forecast, cyclical pattern.
  • Metric: CPUUtilization, RequestCountPerTarget, Network In/Out, custom. Built-in nai (DB request/min) → custom metric + alarm (U08-Q18).
  • Cooldown default 300 s, configurable, ager scaling effect na hoa porjonto launch/terminate na (B2-Q6). Flapping → cooldown barao (B5-Q6). Ready-to-use AMI → cooldown komao; detailed monitoring = 1 min metric.
  • Duita policy ekshathe → largest capacity (S5-Q47).
