21·1U21-Q1Udemy quiz · sec 21 · Q1

Which database helps you store relational datasets, with SQL language compatibility and the capability of processing transactions such as insert, update, and delete?

কোন database আপনাকে relational dataset store করতে সাহায্য করে, যাতে SQL language compatibility এবং insert, update ও delete-এর মতো transaction process করার capability আছে?

Correct: B. Why it is right

Relational dataset + SQL + transaction (insert, update, delete) = RDBMS / OLTP. Course er database type slide e RDBMS (SQL / OLTP) mane RDS ba Aurora (PDF p. 518).

RDS summary (PDF p. 519): managed PostgreSQL / MySQL / Oracle / SQL Server / DB2 / MariaDB, use case "store relational datasets, perform SQL queries, transactions". Tai Amazon RDS.

Why the other options are wrong

  • A. DocumentDB holo MongoDB-compatible NoSQL document (JSON) database; relational table ar SQL er jonno na.
  • C. DynamoDB key-value / document NoSQL; transaction kora gele-o relational format ar SQL language nai.
  • D. ElastiCache in-memory cache (Redis / Memcached); slide bole SQL use kora jay na, primary relational DB na.

Keyword: relational datasets + SQL + transactions → Amazon RDS

Instructor feedback (English)

C: Amazon DynamoDB is a key-value, document, NoSQL database. It does not have SQL and does not store the data in a relational format, but can be used for transactional processing.

D: Amazon ElastiCache is a caching technology and it doesn't have SQL capabilities.

21·2U21-Q2Udemy quiz · sec 21 · Q2

Which AWS service provides you with caching capability that is compatible with Redis API?

কোন AWS service আপনাকে Redis API-compatible caching capability দেয়?

Correct: D. Why it is right

ElastiCache = managed Redis / Memcached (PDF p. 521): in-memory data store, sub-millisecond latency. Redis API compatible caching chaile ekmatro uttor eta-i.

Ajke Redis ke docs e "Redis OSS" bole, ar Valkey engine o ache (Section 09); concept ek-i.

Why the other options are wrong

  • A. RDS relational database, caching service na, Redis API o bojhe na.
  • B. DynamoDB key-value store hisabe ElastiCache er jaygay bosano jay, kintu Redis API support kore na (nijer API).
  • C. OpenSearch search / indexing service, HTTP API diye kaaj kore; Redis-compatible cache na.

Keyword: caching + Redis API → ElastiCache

Instructor feedback (English)

A: Amazon RDS does not have caching capability and it is based on JDBC and not compatible with Redis API.

B: Amazon DynamoDB can be used as a substitute for Redis but it does not support Redis API.

C: Amazon OpenSearch helps you in indexing and searching through your data. It leverages HTTP for client interactions.

D: Amazon ElastiCache is a fully managed in-memory data store, compatible with Redis or Memcached.

21·3U21-Q3Udemy quiz · sec 21 · Q3⚠ outdated

You want to migrate an on-premises MongoDB NoSQL database to AWS. You don't want to manage any database servers, so you want to use a managed NoSQL Serverless database, that provides you with high availability, durability, and reliability, and the capability to take your database global. Which database should you choose?

আপনি একটি on-premises MongoDB NoSQL database AWS-এ migrate করতে চান। আপনি কোনো database server manage করতে চান না, তাই একটি managed NoSQL Serverless database ব্যবহার করতে চান, যা আপনাকে high availability, durability ও reliability দেয়, এবং আপনার database-কে global করার capability দেয়। কোন database বেছে নেওয়া উচিত?

⚠ Outdated: Explanation bole DocumentDB er serverless ar global feature nai - eta ekhon puran. DocumentDB Global Clusters (2021 theke) ar DocumentDB Serverless (July 2025 GA) dutoi ache, tai MongoDB migration e C (DocumentDB) o ekhon fit kore. Course/exam er answer ekhono DynamoDB. source

Correct: B. Why it is right

Course er answer DynamoDB: chawa holo managed NoSQL Serverless, HA + durability, ar global korar khomota. DynamoDB serverless, default e multi-AZ, ar Global Tables diye active-active multi-region (PDF p. 522).

MongoDB theke DynamoDB te gele data model / code bodlate hobe, kintu question er decisive shobdo "serverless" + "global". Course likhar shomoy DocumentDB e serverless / global option chilo na, tai DynamoDB.

Ajke: DocumentDB e Global Clusters (2021) ar DocumentDB Serverless (July 2025 GA) dutoi ache, tai C-o ekhon fit kore; exam / course key tobuo DynamoDB.

Why the other options are wrong

  • A. RDS relational, SQL-based; NoSQL na, serverless o na (instance provision lage).
  • C. Course er explanation: DocumentDB MongoDB-compatible, kintu tokhon serverless ar global feature chilo na. Ajke dutoi ache, tai bastobe defensible; tobu course key DynamoDB.
  • D. Aurora relational (MySQL / PostgreSQL compatible), NoSQL na.

Keyword: managed NoSQL Serverless + take your database global → DynamoDB (Global Tables)

Instructor feedback (English)

A: Amazon RDS is a relational, SQL-based database.

B: Amazon DynamoDB is a key-value, document, NoSQL database.

C: Amazon DocumentDB is a NoSQL databases and it might work perfectly here. But the questions states that the database must be Serverless and wants to take the database global. DocumentDB doesn't have a Serverless option and it doesn't have a global database feature.

D: Amazon Aurora is a relational, SQL-based database.

21·4U21-Q4Udemy quiz · sec 21 · Q4

You are looking to perform Online Transaction Processing (OLTP). You would like to use a database that has built-in auto-scaling capabilities and provides you with the maximum number of replicas for its underlying storage. What AWS service do you recommend?

আপনি Online Transaction Processing (OLTP) করতে চাইছেন। আপনি এমন একটি database ব্যবহার করতে চান, যাতে built-in auto-scaling capability আছে এবং যা তার underlying storage-এর জন্য সর্বোচ্চ সংখ্যক replica দেয়। আপনি কোন AWS service recommend করবেন?

Correct: C. Why it is right

Aurora storage e data 6 replica, 3 AZ te (bodlano jay na), self-healing, storage auto-scaling; read replica o auto-scale hoy (PDF p. 520). Tai "OLTP + built-in auto-scaling + underlying storage er maximum replica" → Aurora.

Aurora PostgreSQL / MySQL compatible relational DB, tai OLTP er jonno thik.

Why the other options are wrong

  • A. ElastiCache in-memory cache, OLTP database na, SQL nai.
  • B. Neptune graph database; highly connected data er jonno, OLTP relational workload er jonno na.
  • D. RDS e built-in storage replication ei rokom nai: read replica ar Multi-AZ nije enable korte hoy, data 6 copy hoy na.

Keyword: OLTP + built-in auto-scaling + maximum replicas for storage → Aurora (6 copies, 3 AZ)

Instructor feedback (English)

A: Amazon ElastiCache is an in-memory data store, provides you with caching capabilities. It is compatible with Redis and Memcached. It does not support OLTP.

C: Amazon Aurora is a MySQL and PostgreSQL-compatible relational database. It features a distributed, fault-tolerant, self-healing storage system that auto-scales up to 128TB per database instance. It delivers high performance and availability with up to 15 low-latency read replicas, point-in-time recovery, continuous backup to Amazon S3, and replication across 3 AZs.

D: Amazon RDS does not have built-in auto-scaling and data replication capabilities. You need to create RDS Read Replicas and enable Multi-AZ.

21·5U21-Q5Udemy quiz · sec 21 · Q5

As a Solutions Architect, a startup company asked you for help as they are working on an architecture for a social media website where users can be friends with each other, and like each other's posts. The company plan on performing some complicated queries such as "What are the number of likes on the posts that have been posted by the friends of Mike?". Which database do you recommend?

একজন Solutions Architect হিসেবে, একটি startup company আপনার সাহায্য চেয়েছে, কারণ তারা একটি social media website-এর architecture নিয়ে কাজ করছে, যেখানে user-রা একে অপরের friend হতে পারবে এবং একে অপরের post like করতে পারবে। company কিছু জটিল query চালানোর পরিকল্পনা করছে, যেমন "What are the number of likes on the posts that have been posted by the friends of Mike?"। আপনি কোন database recommend করবেন?

Correct: C. Why it is right

Friends, likes, posts sob ekta arektar shathe jora = graph dataset. "Mike er friend der post e koto like" = graph traversal query.

Neptune fully managed graph DB, highly connected dataset er complex query er jonno optimized, billions relation ms e query; use case social networking (PDF p. 525).

Why the other options are wrong

  • A. RDS diye join kore kora jay, kintu onek hop er relationship query kothin ar slow; graph DB beshi uposhukto.
  • B. QLDB immutable financial ledger, relationship query er jonno na.
  • D. OpenSearch free text / unstructured search er jonno; kaaj chalano jay kintu graph traversal er jonno banano na.

Keyword: social media, friends, likes, complex relationship query → Neptune

Instructor feedback (English)

A: This would work, but a graph database is better suited.

C: Amazon Neptune is a fast, reliable, fully-managed graph database service that makes it easy to build and run applications that work with highly connected datasets.

D: This would work, but a graph database is better suited.

21·6U21-Q6Udemy quiz · sec 21 · Q6

You have a set of files, 100MB each, that you want to store in a reliable and durable key-value store. Which AWS service do you recommend?

আপনার কাছে কিছু file আছে, প্রতিটি 100MB, যেগুলো আপনি একটি reliable ও durable key-value store-এ store করতে চান। আপনি কোন AWS service recommend করবেন?

Correct: B. Why it is right

S3 = object er key-value store (key = bucket e object er puro path). Boro object er jonno great, serverless, infinitely scale, durable (PDF p. 523). 100 MB file rakhar jonno sothik.

Why the other options are wrong

  • A. Aurora relational database; boro file (BLOB) rakhar jonno na.
  • C. DynamoDB item max 400 KB, tai 100 MB file rakha jay na; choto document (100s KB) er jonno.
  • D. ElastiCache in-memory cache, durable na, boro object rakhar jonno na.

Keyword: files, 100 MB each + durable key-value store → S3

Instructor feedback (English)

B: Amazon S3 is indeed a key-value store! (where the key is the full path of the object in the bucket)

C: Amazon DynamoDB can not be used to store big objects. The maximum item size in DynamoDB is 400KB.

D: Amazon ElastiCache is a fully managed in-memory data store, compatible with Redis or Memcached. It can not be used to store big objects, in addition to it is not durable.

21·7U21-Q7Udemy quiz · sec 21 · Q7

A company has an on-premises website that uses ReactJS as its frontend, NodeJS as its backend, and MongoDB for the database. There are some issues with the self-hosted MongoDB database as there is a lot of maintenance required and they don’t have and can’t afford the resources or experience to handle those issues. So, a decision was made to migrate the website to AWS. They have decided to host the frontend ReactJS application in an S3 bucket and the NodeJS backend on a set of EC2 instances. Which AWS service can they use to migrate the MongoDB database that provides them with high scalability and availability without making any code changes?

একটি company-র একটি on-premises website আছে, যা frontend হিসেবে ReactJS, backend হিসেবে NodeJS এবং database হিসেবে MongoDB ব্যবহার করে। self-hosted MongoDB database-এ কিছু সমস্যা আছে, কারণ অনেক maintenance লাগে, এবং এই সমস্যাগুলো handle করার মতো resource বা অভিজ্ঞতা তাদের নেই এবং তার খরচও তারা বহন করতে পারবে না। তাই website-টি AWS-এ migrate করার সিদ্ধান্ত নেওয়া হয়েছে। তারা frontend ReactJS application একটি S3 bucket-এ এবং NodeJS backend কিছু EC2 instance-এ host করার সিদ্ধান্ত নিয়েছে। কোনো code change না করেই high scalability ও availability দেয় এমনভাবে MongoDB database migrate করতে তারা কোন AWS service ব্যবহার করতে পারে?

Correct: B. Why it is right

DocumentDB holo MongoDB er jonno AWS er "Aurora": MongoDB-compatible, fully managed, 3 AZ replication, storage auto-grow, millions req/s porjonto scale (PDF p. 524).

MongoDB-compatible bole NodeJS backend er MongoDB driver / query ek-i thake: code change lage na, ar maintenance AWS er.

Why the other options are wrong

  • A. ElastiCache Redis / Memcached cache; MongoDB compatible na, primary database o na.
  • C. "RDS for MongoDB" bole kono service nai; RDS shudhu relational engine (PostgreSQL, MySQL, MariaDB, Oracle, SQL Server, DB2).
  • D. Neptune graph database; MongoDB document model ar API er shathe compatible na.

Keyword: MongoDB migrate + no code changes → DocumentDB

21·8U21-Q8Udemy quiz · sec 21 · Q8

A company using a self-hosted on-premises Apache Cassandra database which they want to migrate to AWS. Which AWS service can they use which provides them with a fully managed, highly available, and scalable Apache Cassandra database?

একটি company একটি self-hosted on-premises Apache Cassandra database ব্যবহার করছে, যা তারা AWS-এ migrate করতে চায়। কোন AWS service তারা ব্যবহার করতে পারে, যা তাদের একটি fully managed, highly available ও scalable Apache Cassandra database দেয়?

Correct: D. Why it is right

Amazon Keyspaces = managed Apache Cassandra-compatible database: serverless, scalable, highly available, 3 copy across AZ, CQL diye query (PDF p. 527). Course: "Apache Cassandra dekhle Keyspaces".

Why the other options are wrong

  • A. DocumentDB MongoDB-compatible, Cassandra na.
  • B. DynamoDB NoSQL ar serverless, kintu Cassandra / CQL compatible na; migrate korte code bodlate hobe.
  • C. Timestream time series database, Cassandra-compatible na.

Keyword: Apache Cassandra fully managed → Amazon Keyspaces

21·9U21-Q9Udemy quiz · sec 21 · Q9⚠ outdated

An online payment company is using AWS to host its infrastructure. Due to the application’s nature, they have a strict requirement to store an accurate record of financial transactions such as credit and debit transactions. Those transactions must be stored in secured, immutable, encrypted storage which can be cryptographically verified. Which AWS service is best suited for this use case?

একটি online payment company তাদের infrastructure host করতে AWS ব্যবহার করছে। application-এর প্রকৃতির কারণে তাদের একটি কঠোর requirement আছে: credit ও debit transaction-এর মতো financial transaction-এর একটি নির্ভুল record store করতে হবে। এই transaction-গুলো secured, immutable, encrypted storage-এ store করতে হবে, যা cryptographically verify করা যায়। এই use case-এর জন্য কোন AWS service সবচেয়ে উপযুক্ত (best suited)?

⚠ Outdated: Amazon QLDB 31 July 2025 e end of support (full shutdown) hoye geche, ekhon ar use kora jay na; AWS ledger/audit use case er jonno Aurora PostgreSQL e migrate korte bole. Course/exam er answer ekhono QLDB ('immutable, cryptographically verifiable' = QLDB). source

Correct: C. Why it is right

QLDB = ledger database: fully managed, serverless, 3 AZ. Journal e protita change er cryptographic hash hoy, tai data immutable ar je keu cryptographically verify korte pare kichu delete / modify hoy ni. Financial transaction er jonno course er answer.

Ajke: QLDB 31 July 2025 e end of support (full shutdown); AWS ledger / audit er jonno Aurora PostgreSQL e migrate korte bole. Course / exam answer tobuo QLDB.

Why the other options are wrong

  • A. DocumentDB JSON document DB; immutable journal ba cryptographic verification nai.
  • B. Aurora relational DB; data update / delete kora jay, built-in cryptographic verification nai.
  • D. Neptune graph DB, relationship query er jonno; ledger na.

Keyword: financial transactions + immutable + cryptographically verified → QLDB

21·10U21-Q10Udemy quiz · sec 21 · Q10⚠ outdated

A startup is working on developing a new project to reduce forest fires due to climate change. The startup is developing sensors that will be spread across the entire forest to make some readings such as temperature, humidity, and pressures which will help detect the forest fires before it happens. They are going to have thousands of sensors that are going to store a lot of readings each second. There is a requirement to store those readings and do fast analytics so they can predict if there is a fire. Which AWS service can they use to store those readings?

একটি startup climate change-এর কারণে হওয়া বনের আগুন (forest fire) কমাতে একটি নতুন project তৈরির কাজ করছে। startup এমন sensor তৈরি করছে, যেগুলো পুরো বন জুড়ে ছড়িয়ে রাখা হবে এবং temperature, humidity ও pressure-এর মতো কিছু reading নেবে, যা forest fire ঘটার আগেই তা detect করতে সাহায্য করবে। তাদের হাজার হাজার sensor থাকবে, যেগুলো প্রতি সেকেন্ডে অনেক reading store করবে। এই reading-গুলো store করে দ্রুত analytics করার requirement আছে, যাতে তারা আগুন লাগবে কিনা predict করতে পারে। এই reading-গুলো store করতে তারা কোন AWS service ব্যবহার করতে পারে?

⚠ Outdated: Amazon Timestream for LiveAnalytics 20 June 2025 theke new customer der jonno bondho; new user der jonno Timestream for InfluxDB ache. Time-series data = Timestream, course/exam er answer ekhono eta-i. source

Correct: A. Why it is right

Sensor er reading (temperature, humidity, pressure) protita second e = time series data. Timestream serverless time series DB: trillions events/day, recent data memory te, built-in time series analytics function diye near real-time pattern; use case IoT, real-time analytics (PDF p. 528).

Ajke: Timestream for LiveAnalytics 20 June 2025 theke notun customer der jonno bondho; notun user der jonno Timestream for InfluxDB. Exam answer tobuo Timestream.

Why the other options are wrong

  • B. Neptune graph database; sensor reading er time series data ar fast time-based analytics er jonno na.
  • C. S3 e store kora jay, kintu fast time series analytics database na.
  • D. ElastiCache in-memory cache, durable long-term store na, analytics o na.

Keyword: thousands of sensors, readings each second, fast analytics → Timestream
