11·1S3-Q49Stephane set 3 · Q49Design Cost-Optimized Architecturesnot in course

A fashion blogger is looking at starting a Wordpress blog on AWS Cloud. He estimates the blog traffic to be a few thousand users a month, wants the infrastructure fee to be a fixed price per month and the Wordpress blog should be offered as a preconfigured deployment option as he does not want to deal with code. Which AWS service is the BEST fit for the given use-case?

একজন fashion blogger AWS Cloud-এ একটি Wordpress blog শুরু করার কথা ভাবছেন। তাঁর অনুমান blog traffic মাসে কয়েক হাজার user হবে; তিনি চান infrastructure fee প্রতি মাসে একটি fixed price হোক এবং Wordpress blog-টি একটি preconfigured deployment option হিসেবে দেওয়া হোক, কারণ তিনি code নিয়ে কাজ করতে চান না। দেওয়া use-case-এর জন্য কোন AWS service সবচেয়ে উপযুক্ত (BEST fit)?

Not in the course: Amazon Lightsail course e nai.

Correct: A. Why it is right

Amazon Lightsail (course e nai): easy cloud platform, fixed monthly plan, ar preconfigured one-click app, WordPress soho. Code nije lekha ba manage lage na.

Choto traffic (kichu hajar user/mash) + fixed dam + WordPress ready → Lightsail.

Why the other options are wrong

  • B. Lambda code run kore (pay per compute time); WordPress blog Lambda function e host kora jay na.
  • C. EC2 er dam variable, ar WordPress nije install o manage korte hobe. Fixed price, preconfigured na.
  • D. Beanstalk e nijer code upload korte hoy; blogger code deal korte chay na. Dam-o fixed na (resource er dam).

Keyword: fixed price per month + preconfigured WordPress + no code → Lightsail

Original explanation (English)

Correct option: "Lightsail"

Lightsail is an easy-to-use cloud platform that offers you everything needed to build an application or website, plus a cost-effective, monthly plan. Lightsail offers several preconfigured, one-click-to-launch operating systems, development stacks, and web applications, including Linux, Windows OS, and WordPress. Therefore, this is the best fit for the given use-case.

Incorrect options: "Lambda" - AWS Lambda lets you run code without provisioning or managing servers. You pay only for the compute time you consume. You cannot set up a Wordpress blog on a Lambda function.

"EC2 instance" - An EC2 instance is a virtual server in Amazon's Elastic Compute Cloud (EC2) for running applications on the Amazon Web Services (AWS) infrastructure. EC2 instances come with variable pricing. Additionally, the blog would need to be installed manually on the underlying virtual server. Therefore, this option is not correct.

"Elastic Beanstalk" - AWS Elastic Beanstalk is an easy-to-use service for deploying and scaling web applications and services developed with Java, .NET, PHP, Node.js, Python, Ruby, Go, and Docker on familiar servers such as Apache, Nginx, Passenger, and IIS. You can simply upload your code and Elastic Beanstalk automatically handles the deployment, from capacity provisioning, load balancing, auto-scaling to application health monitoring. As the blogger does not want to deal with code, this option is not correct.

Reference: https://aws.amazon.com/lightsail/

11·2S4-Q1Stephane set 4 · Q1Design Resilient Architectures

Your company is deploying a website running on Elastic Beanstalk. That website takes over 45 minutes to install and contains both static and dynamic files that must be generated during the installation process. As a Solutions Architect, you would like to bring the time to create a new Instance in your Elastic Beanstalk deployment to being less than 2 minutes. What do you recommend? (select two)

আপনার company Elastic Beanstalk-এ চলা একটি website deploy করছে। website-টি install হতে 45 মিনিটের বেশি সময় নেয় এবং এতে static ও dynamic দুই ধরনের file আছে, যেগুলো installation process-এর সময় generate করতে হয়। একজন Solutions Architect হিসেবে, আপনি চান আপনার Elastic Beanstalk deployment-এ একটি নতুন Instance তৈরির সময় 2 মিনিটের কম হোক। আপনি কী recommend করবেন? (2টি বেছে নিন) (select two)

Choose 2 answers

Correct: A, B. Why it is right

Course er hybrid pattern: Golden AMI + User Data; Elastic Beanstalk ei principle use kore (PDF p. 260).

  • Golden AMI: 45 min er static install age theke AMI te; boot e reinstall lage na.
  • User Data: boot er somoy shudhu choto dynamic part (generate korte hoy emon file) toiri kore.

Duita mile 2 minute er moddhe instance ready. Beanstalk e custom AMI dewa jay.

Why the other options are wrong

  • C. S3 theke file druto download hote pare, kintu install ekhono boot e chole, 45 min lagbe.
  • D. Puro install User Data te dile protita instance e boot e 45 min install chole; 2 min target hobe na.
  • E. Beanstalk e 'deployment caching' namer kono feature nai; distractor.

Keyword: static + dynamic files + 45 min theke < 2 min → Golden AMI (static) + User Data (dynamic)

Original explanation (English)

When you create an AWS Elastic Beanstalk environment, you can specify an Amazon Machine Image (AMI) to use instead of the standard Elastic Beanstalk AMI included in your platform version. A custom AMI can improve provisioning times when instances are launched in your environment if you need to install a lot of software that isn't included in the standard AMIs. Read more here: https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/using-features.customenv.html

References: https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/using-features.customenv.html
