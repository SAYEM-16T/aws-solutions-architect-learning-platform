23·1U23-Q1Udemy quiz · sec 23 · Q1

You should use Amazon Transcribe to turn text into lifelike speech using deep learning.

deep learning ব্যবহার করে text-কে প্রাণবন্ত (lifelike) speech-এ পরিণত করতে আপনার Amazon Transcribe ব্যবহার করা উচিত।

Correct: B. Why it is right

Statement ta False. Amazon Transcribe kore ulta kaaj: speech → text (ASR) (PDF p. 566).

Why the other options are wrong

  • A. Transcribe text → speech kore na; eta speech → text. Text → lifelike speech holo Polly er kaaj.

Keyword: text into lifelike speech → Polly, Transcribe na → False

Instructor feedback (English)

A: Amazon Transcribe is an AWS service that makes it easy for customers to convert speech-to-text. Amazon Polly is a service that turns text into lifelike speech.

B: Amazon Transcribe is an AWS service that makes it easy for customers to convert speech-to-text. Amazon Polly is a service that turns text into lifelike speech.

23·12U23-Q12Udemy quiz · sec 23 · Q12

Amazon Polly allows you to turn text into speech. It has two important features. First is ……………….. which allows you to customize the pronunciation of words (e.g., “Amazon EC2” will be “Amazon Elastic Compute Cloud”). The second is ……………….. which allows you to emphasize words, including breathing sounds, whispering, and more.

Amazon Polly দিয়ে আপনি text-কে speech-এ রূপান্তর করতে পারেন। এর দুটি গুরুত্বপূর্ণ feature আছে। প্রথমটি হলো ……………….., যা দিয়ে আপনি শব্দের উচ্চারণ customize করতে পারেন (যেমন, “Amazon EC2” হয়ে যাবে “Amazon Elastic Compute Cloud”)। দ্বিতীয়টি হলো ……………….., যা দিয়ে আপনি শব্দে জোর (emphasize) দিতে পারেন, এর মধ্যে breathing sounds, whispering এবং আরও অনেক কিছু আছে।

Correct: C. Why it is right

Polly er duita feature (PDF p. 568):

  • Pronunciation Lexicons: word er uccharon customize: acronym ("AWS" → "Amazon Web Services", ekhane "Amazon EC2" → "Amazon Elastic Compute Cloud") ba stylized word.
  • SSML (Speech Synthesis Markup Language): emphasis, phonetic pronunciation, breathing sound, whispering, Newscaster style.

Tai order: prothome Lexicons, tarpor SSML.

Why the other options are wrong

  • A. Order ulta: pronunciation customize kore Lexicons, ar breathing / whispering kore SSML.
  • B. SAML (Security Assertion Markup Language) identity federation / SSO er jinish, Polly er feature na.
  • D. SAML Polly er feature na, ar order o bhul.

Keyword: customize pronunciation → Lexicons; emphasize, breathing, whispering → SSML
