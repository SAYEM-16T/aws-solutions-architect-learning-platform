Amazon Rekognition

Shohoj kore: CCTV er shamne ekjon smart guard. Chobi ba video dao, Rekognition bolbe "ekhane manush, rock, mountain bike, outdoors; ei meye hashche, chokh khola; ei jon celebrity". Shudhu image ar video; text ba audio na.

Text DetectionDaur protijogitay runner er bib number
Face Detection and AnalysisGender, age range, emotion (smiling, eyes open)
Face Search and VerificationUser verification, people counting, security app; nijer "familiar faces" database
Celebrity RecognitionFamous manush chena (demo te AWS er CTO)
PathingSports game (soccer) e ke kothay jacche, real-time analysis
Content Moderation flow (exam favourite)
Image / video→ Rekognitionpre-trained, training nai→ Confidence level vsMinimum Confidence Threshold→ Flagged→ Amazon A2Ioptional manual review→ Rakho / delete

Machine age auto flag kore; manush (A2I) final decision ney.

  • Inappropriate, unwanted, offensive content (jemon racist, pornography) detect, image ar video duto-tei. Social media, broadcast media, advertising, e-commerce e safer user experience.
  • Minimum Confidence Threshold tumi set koro (percentage). Threshold kom dile beshi match / flag. Confidence = Rekognition koto nishchit je eta offensive.
  • Flag kora content Amazon Augmented AI (A2I) e human review. Post howar age detect korte hoy emon regulation comply korte help kore.
  • Question theke: photo (still image) hole normal Rekognition image API; Rekognition Video video er jonno.
Exam: "Objects, people, text, scenes in images and videos" → Rekognition. "Inappropriate / unwanted image, minimizes development effort, must not involve training, confidence threshold, manual review" → Rekognition (+ A2I). Typical flow: web app photo upload → Lambda (function URL) → Rekognition. Trap: Comprehend (text only), SageMaker / Autopilot / Fargate custom model (training lage), Rekognition Video (photo na). Option e "Amazon Recognition" bhul banan; Rekognition audio theke speaker chene na.

Lexicon = kon word kivabe uccharon; SSML = kivabe bolbe (thama, phishphish, jor).

Amazon Translate

Shohoj kore: Website English e; France, Brazil, India er user der nijer bhashay dekhate chao. Translate natural ar accurate anubad kore (text → text), boro volume er text o druto.

  • Natural and accurate language translation (neural machine translation).
  • Website ar application localize kora, international user der jonno.
  • Large volumes of text efficiently translate. Source ar target language code dao.
Exam: "Different languages", "natural and accurate", "translate text into English" → Translate. Trap: Transcribe (speech → text, bhasha same), Polly (text → speech), Comprehend translate kore na. "WordTranslator" bole kono AWS service nai. Translate entity / sentiment er moto NLP analysis o kore na.

Exam traps

  • "No ML experience", "minimize development effort", "must not involve training" dekhle ready-made service, SageMaker / Autopilot / Ground Truth / Fargate custom model na.
  • Transcribe (shune likhe) ≠ Polly (lekha pore) ≠ Lex (bujhe, chatbot) ≠ Translate (bhasha bodlay).
  • Rekognition = image / video; Textract = document; Comprehend = text er mane; Kendra = search.
  • Report / PDF theke text dekhle Textract, Rekognition na; text theke PHI dekhle Comprehend Medical, SageMaker ba Transcribe Medical na.
  • Photo moderation dekhle normal Rekognition, Rekognition Video na; Comprehend kokhono image dekhe na.
  • "Amazon Recognition" bhul banan; speaker recognition Transcribe, Rekognition na.
  • SSML = Polly; SAML = federation. Blank e Lexicon age (pronunciation), SSML pore (whisper).
  • Moderation threshold kom dile beshi flag (beshi match), kom na.
  • Visual report dekhle QuickSight, Athena na; durable result store DynamoDB / S3, ElastiCache na.
  • Kinesis Data Streams audio file transcribe kore na; Alexa AWS service na (tar technology = Lex).
