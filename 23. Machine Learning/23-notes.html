Lecture 1 · Rekognition Overview · PDF p. 564-565 (part p. 2-3)

Amazon Rekognition: image ar video te ki ache

Shohoj kore (CCTV er shamne ekjon smart guard): Chobi ba video dao, Rekognition bolbe "ekhane manush ache, mountain bike ache, ei lok hashche, ei jon celebrity". ML diye dekha ar chena er kaaj. Text, audio na: shudhu image ar video.

Ki kore (PDF p. 564 (part p. 2))

  • Image ar video te object, people, text, scene khuje (ML diye).
  • Facial analysis ar facial search: user verification, people counting (chobite koto jon).
  • Nijer "familiar faces" database banano jay, ba celebrity der sathe compare.

Content Moderation (PDF p. 565 (part p. 3)): exam er important feature

  • Inappropriate, unwanted, offensive content detect kore, image ar video duto-tei.
  • Kothay: social media, broadcast media, advertising, e-commerce: safer user experience.
  • Minimum Confidence Threshold set koro: tar upore hole item flagged. Threshold kom dile beshi match (beshi flag) hobe.
  • Confidence = Rekognition koto nishchit je eta asolei inappropriate.
  • Flag kora content Amazon Augmented AI (A2I) e optional manual (human) review e pathano jay: rakhbe na delete korbe, manush decide kore.
  • Post korar age detect korte hoy emon regulation comply korte help kore.
Content moderation flow
Image / video→ Rekognitionmoderation→ Confidence levelvs Minimum Threshold→ flagged Amazon A2Ioptional manual review

Machine age auto flag kore, tarpor dorkar hole manush final decision ney.

Exam: "Find objects, people, text, scenes in images and videos" → Rekognition (U23-Q3). "Inappropriate / offensive image ba video auto detect + minimum confidence threshold + manual review" → Rekognition content moderation (+ A2I) (U23-Q10). Face detection, celebrity, labeling → Rekognition. Polly / Lex / Translate / Kendra image dekhe na. Spelling trap: service er naam Rekognition (k diye); "Amazon Recognition" bole option thakle sheta bhul banan.

Subtitle e "CTO of AWS" bola ache (demo chobi); exam e dorkar nai, bad diyechi.

Lecture 3 · Polly Overview · PDF p. 567-568 (part p. 5-6)

Shohoj kore (Transcribe er ulta): Lekha dao, Polly manusher moto gola diye pore shunabe. App ke "kotha bolano" jay. Kothay thamte hobe, fish-fish kore bolte hobe (whisper), "AWS" ke "Amazon Web Services" bolte hobe: egulo control kora jay.

  • Console demo: Neural engine = shobcheye natural, human-like; voice choose kora jay (e.g. Joanna).
