Lecture 6 + 7 (hands-on) · Lambda Concurrency · PDF p. 452-456 (part p. 12-16)

Concurrency, throttling, cold start: reserved vs provisioned

Shohoj kore (ek office er 1000 ta chair): Account e mot 1000 ta chair (concurrency). Sale er din ek team (ALB er function) sob chair dokhol kore nile onno team (API Gateway, CLI) boshar jayga pay na — tara "throttled". Reserved concurrency = protita team er jonno nirdishto chair (ar tar beshi na). Provisioned concurrency = chair e age thekei lok boshano, computer on — kaaj ashle shathe shathe shuru (cold start nai).

Concurrency ar throttling (PDF p. 452 (part p. 12))

  • Beshi invoke = beshi concurrent execution. Kom load e hoyto 2 ta, boro event e up to 1000.
  • Function level e "reserved concurrency" set kora jay = oi function er limit (jemon "max 50"). Eta recommended.
  • Limit er upore protiti invocation = Throttle.
  • 1000 er beshi lagle support ticket khulo.

Asynchronous (jemon S3 event notification)Automatic retry, tarpor DLQ (dead letter queue)

Async invocation ar concurrency (PDF p. 454 (part p. 14))

  • Example: S3 e onek file ek shathe → onek "new file event" → Lambda.
  • Concurrency na thakle extra request throttled.
  • Throttle error (429) ar system error (500-series) hole Lambda event ke internal event queue te ferot rakhe, ar up to 6 ghonta abar chalanor cheshta kore.
  • Retry interval exponential backoff: 1 s theke shuru, max 5 min por por.

Hands-on (Lecture 7): Configuration → Concurrency

  • Shuru te function unreserved account concurrency use kore: account e 1000, sob function er moddhe shared.
  • Reserve 20 korle: oi function 20, baki sob function er jonno 980 unreserved.
  • Reserve 0 = function shob shomoy throttled ("Rate exceeded") — throttle handling test korar bhalo upay.
  • Provisioned concurrency config: alias ba version e set hoy, $LATEST e na (version publish lage). Free na, cost ache.
Exam:
  • SNS → Lambda, peak e 5000 req/s, notification harachhe → account concurrency quota par; support e limit barao. "SNS limit" ba "server provision" = bhul (S1-Q50).
  • Ek function onno function ke starve korche → reserved concurrency.
  • Cold start / first request slow / predictable low latency → provisioned concurrency (ba SnapStart, Lecture 8).
  • Sync throttle = 429; async = retry (6 h porjonto) → DLQ. Bar bar fail kora message alada kore rakhte dead-letter queue (S3-Q44).

Customization at the edge (PDF p. 458-459 (part p. 18-19))

  • Duita type: CloudFront Functions ar Lambda@Edge. Server manage nai, globally deployed, pay per use, fully serverless. Use: CDN content customize.
  • Use cases: website security & privacy, dynamic web app at edge, SEO, origin / data center er moddhe intelligent routing, bot mitigation, real-time image transformation, A/B testing, user authentication & authorization, user prioritization, user tracking & analytics.
