13·1U13-Q1Udemy quiz · sec 13 · Q1

How can you be notified when there's an object uploaded to your S3 bucket?

আপনার S3 bucket-এ কোনো object upload হলে আপনি কীভাবে notification পেতে পারেন?

Correct: C. Why it is right

S3 Event Notifications: bucket e S3:ObjectCreated, ObjectRemoved, ObjectRestore, Replication event hole SNS, SQS ba Lambda te notification jay (PDF p. 301). Object upload = ObjectCreated event.

Chaile sob event EventBridge e-o pathano jay.

Why the other options are wrong

  • A. S3 Select object er moddhe SQL diye kichu data filter kore pore; notification dey na. (Ar S3 Select ekhon notun customer der jonno bondho.)
  • B. Access Logs bucket e asha request er log onno bucket e likhe rakhe; pore analysis er jonno, upload e notify kore na.
  • D. S3 Analytics (Storage Class Analysis) koto din por transition korbe tar recommendation dey; event notification na.

Keyword: notified when object uploaded → S3 Event Notifications

13·2U13-Q2Udemy quiz · sec 13 · Q2

You have an S3 bucket that has S3 Versioning enabled. This S3 bucket has a lot of objects, and you would like to remove old object versions to reduce costs. What's the best approach to automate the deletion of these old object versions?

আপনার একটি S3 bucket আছে, যেখানে S3 Versioning enabled। এই S3 bucket-এ অনেক object আছে, এবং cost কমাতে আপনি পুরনো object version-গুলো সরিয়ে ফেলতে চান। এই পুরনো object version-গুলোর deletion automate করার সবচেয়ে ভালো approach কী?

Correct: B. Why it is right

Lifecycle Rule e Expiration actions object ke nirdishto din por delete kore, ar versioning on thakle old (noncurrent) version o delete korte pare (PDF p. 296).

Console e action: 'Permanently delete noncurrent versions of objects'. Purono version jome cost barche → expiration diye automatic porishkar.

Why the other options are wrong

  • A. Transition actions object ke sostar storage class e shoray, delete kore na. Cost kichu kome, kintu purono version theke-i jay.
  • C. Access Logs shudhu request er log rakhe; kono object ba version delete kore na.

Keyword: remove old object versions + automate → Lifecycle Expiration actions

13·3U13-Q3Udemy quiz · sec 13 · Q3

How can you automate the transition of S3 objects between their different tiers?

S3 object-গুলোর বিভিন্ন tier-এর মধ্যে transition আপনি কীভাবে automate করতে পারেন?

Renamed: CloudWatch Events -> Amazon EventBridge (the answer is the same).

Correct: C. Why it is right

S3 Lifecycle Rules er transition actions object ke automatic onno storage class e shoray, ex: 60 din por Standard-IA, 6 mash por Glacier (PDF p. 295-296).

Native S3 feature, kono code ba server lage na.

Why the other options are wrong

  • A. Lambda diye nije code likhe class bodlano somvob, kintu custom code, maintenance ar cost; native automatic upay Lifecycle Rules.
  • B. CloudWatch Events (ekhon Amazon EventBridge) event route ba schedule kore; nije storage class transition kore na.

Keyword: automate transition between tiers → S3 Lifecycle Rules

13·4U13-Q4Udemy quiz · sec 13 · Q4

While you're uploading large files to an S3 bucket using Multi-part Upload, there are a lot of unfinished parts stored in the S3 bucket due to network issues. You are not using these unfinished parts and they cost you money. What is the best approach to remove these unfinished parts?

Multi-part Upload ব্যবহার করে একটি S3 bucket-এ বড় file upload করার সময় network সমস্যার কারণে S3 bucket-এ অনেক unfinished part store হয়ে আছে। আপনি এই unfinished part-গুলো ব্যবহার করছেন না এবং এগুলোর জন্য আপনার টাকা খরচ হচ্ছে। এই unfinished part-গুলো সরানোর সবচেয়ে ভালো approach কী?

Correct: C. Why it is right

Lifecycle Rule er expiration diye incomplete multi-part upload nirdishto din por automatic delete kora jay (PDF p. 296; console action: 'Delete expired object delete markers or incomplete multipart uploads').

Ekbar rule dile S3 nije porishkar kore, kono code ba manual kaj lage na.

Why the other options are wrong

  • A. Lambda loop kaj korbe, kintu onek manual code, maintenance ar beshi cost. Native lifecycle rule thakte eta best na.
  • B. AWS Support tomar bucket er data delete kore dey na; eta tomar nijer kaj, lifecycle rule diye automate koro.

Keyword: unfinished parts of Multi-part Upload + cost → Lifecycle Policy

Instructor feedback (English)

A: This would work but it includes a lot of manual work and will cost you more money.

13·5U13-Q5Udemy quiz · sec 13 · Q5

You are looking to get recommendations for S3 Lifecycle Rules. How can you analyze the optimal number of days to move objects between different storage tiers?

আপনি S3 Lifecycle Rules-এর জন্য recommendation পেতে চাইছেন। বিভিন্ন storage tier-এর মধ্যে object সরানোর optimal দিনের সংখ্যা আপনি কীভাবে analyze করতে পারেন?

Correct: B. Why it is right

S3 Analytics (Storage Class Analysis) bucket er access pattern dekhe daily .csv report dey: koto din por object onno class e nile bhalo (PDF p. 299).

Lifecycle Rule banano ba improve korar prothom step. Mone rakho: recommendation shudhu Standard ar Standard-IA er jonno, report shuru hote 24-48 ghonta.

Why the other options are wrong

  • A. S3 Inventory bucket er object er list ar metadata report dey (ex: Batch Operations er jonno); koto din por transition korbe tar recommendation dey na.
  • C. 'S3 Lifecycle Rules Advisor' namer kono feature nai; distractor.

Keyword: recommendations + optimal number of days to move → S3 Analytics

13·6U13-Q6Udemy quiz · sec 13 · Q6⚠ outdated

You are looking to build an index of your files in S3, using Amazon RDS PostgreSQL. To build this index, it is necessary to read the first 250 bytes of each object in S3, which contains some metadata about the content of the file itself. There are over 100,000 files in your S3 bucket, amounting to 50 TB of data. How can you build this index efficiently?

আপনি Amazon RDS PostgreSQL ব্যবহার করে S3-এ থাকা আপনার file-গুলোর একটি index তৈরি করতে চান। এই index তৈরি করতে S3-এর প্রতিটি object-এর প্রথম 250 bytes read করা দরকার, যেখানে file-এর content সম্পর্কে কিছু metadata আছে। আপনার S3 bucket-এ 100,000-এর বেশি file আছে, মোট 50 TB data। কীভাবে আপনি এই index efficiently তৈরি করতে পারেন?

⚠ Outdated: Option D er S3 Select July 2024 theke new customer der jonno available na (shudhu existing customer use korte pare), course slide eo ar nai. Tai ei type kaje Byte-Range Fetch (key) i thik. source

Correct: C. Why it is right

Byte-Range Fetch: GET request e shudhu nirdishto byte range chao. Course e use case: file er prothom kichu byte e header thakle shudhu oi range ano (PDF p. 306).

100,000 file er prothom 250 byte = khub choto data; 50 TB puro download kora lage na. Tai efficient.

Aj: option D er S3 Select July 2024 theke notun customer der jonno available na (shudhu existing customer), tai ei kaje Byte-Range Fetch-i thik.

Why the other options are wrong

  • A. RDS PostgreSQL S3 theke import korte pare (aws_s3 extension), kintu tate puro 50 TB data load hobe; slow ar dami, index er jonno shudhu 250 byte lage.
  • B. Sob file puro read korle 50 TB download hobe; kaj korbe, kintu khub slow ar dami. Efficient na.
  • D. S3 Select SQL diye filter kore, 'first 250 bytes' anar tool na (eta ScanRange use kore); ar ekhon notun customer der jonno bondho. Simple ranged GET-i bhalo.

Keyword: first 250 bytes of each object + efficiently → Byte Range Fetch

13·7U13-Q7Udemy quiz · sec 13 · Q7

You have a large dataset stored on-premises that you want to upload to the S3 bucket. The dataset is divided into 10 GB files. You have good bandwidth but your Internet connection isn't stable. What is the best way to upload this dataset to S3 and ensure that the process is fast and avoid any problems with the Internet connection?

আপনার on-premises-এ store করা একটি বড় dataset আছে, যা আপনি S3 bucket-এ upload করতে চান। dataset-টি 10 GB-র file-এ ভাগ করা। আপনার bandwidth ভালো, কিন্তু Internet connection stable নয়। এই dataset S3-এ upload করার এবং process দ্রুত রাখা ও Internet connection-এর যেকোনো সমস্যা এড়ানো নিশ্চিত করার সবচেয়ে ভালো উপায় কী?

Correct: C. Why it is right

  • Multi-part Upload: 10 GB file part e bhag hoye parallel upload; connection unstable hole shudhu fail kora part abar pathao (5 GB er beshi file e must, PDF p. 305).
  • Transfer Acceleration: kacher edge location e upload, tarpor private AWS network e bucket e, tai fast (PDF p. 305).

Duita compatible; fast + unstable internet duita problem-i mitay.

Why the other options are wrong

  • A. Multi-part unstable connection handle kore, kintu Transfer Acceleration chara speed er extra boost nai. 'Fast' requirement puro hoy na.
  • B. S3 Select data query kore, upload er sathe somporko nai (ar notun customer der jonno bondho). Multi-part chara unstable internet e 10 GB file fail hole abar shuru theke.

Keyword: 10 GB files + Internet not stable + fast → Multi-part Upload + Transfer Acceleration

13·8U13-Q8Udemy quiz · sec 13 · Q8

A company is preparing for compliance and regulatory review on its infrastructure on AWS. Currently, they have their files stored on S3 buckets encrypted using S3 Default Encryption, which must be encrypted using KMS as required for compliance and regulatory review. Which S3 feature allows them to encrypt all files in their S3 buckets in the most efficient and cost-effective way?

একটি company AWS-এ তাদের infrastructure-এর compliance ও regulatory review-এর জন্য প্রস্তুতি নিচ্ছে। বর্তমানে তাদের file-গুলো S3 Default Encryption দিয়ে encrypt করা S3 bucket-এ store করা আছে, কিন্তু compliance ও regulatory review-এর requirement অনুযায়ী এগুলো KMS দিয়ে encrypt করতে হবে। কোন S3 feature তাদের S3 bucket-এর সব file সবচেয়ে efficient ও cost-effective উপায়ে encrypt করতে দেয়?

Correct: C. Why it is right

S3 Batch Operations existing onek object e ek job e bulk kaj kore; course e main use case: unencrypted/existing object encrypt kora (PDF p. 307).

Retry, progress tracking, completion notification, report nije kore, tai script er cheye efficient. Sob file KMS e re-encrypt → Batch Operations.

Why the other options are wrong

  • A. Access Points bucket e access manage korar alada entry point ar policy dey; object encrypt kore na.
  • B. Cross-Region Replication onno region er bucket e copy kore, shudhu enable korar por notun object; existing file encrypt korar efficient upay na.
  • D. Lifecycle Rules shudhu transition ba expire kore; encryption bodlay na.

Keyword: encrypt all (existing) files with KMS + efficient, cost-effective → S3 Batch Operations

13·9U13-Q9Udemy quiz · sec 13 · Q9⚠ outdated

You have a 25 GB file that you're trying to upload to S3 but you're getting errors. What is a possible solution for this?

আপনার একটি 25 GB file আছে, যা আপনি S3-এ upload করার চেষ্টা করছেন কিন্তু error পাচ্ছেন। এর একটি সম্ভাব্য solution কী?

⚠ Outdated: Explanation e bola 'S3 file size limit 5 TB', kintu Dec 2025 theke S3 er max object size 50 TB (course slide v49 o 50TB bole). Single PUT limit ekhono 5 GB, tai 25 GB file e Multi-part Upload lagbe, answer thik. source

Correct: C. Why it is right

Ek single PUT e max 5 GB upload hoy. 25 GB file tai single upload e error dey. Multi-part upload 100 MB er beshi e recommended, 5 GB er beshi e must (PDF p. 305).

Aj: S3 er max object size Dec 2025 theke 50 TB (explanation er '5 TB' purono), kintu single PUT limit ekhono 5 GB, tai answer same.

Why the other options are wrong

  • A. Bhul: S3 object er limit 5 GB na (ekhon max 50 TB). 5 GB holo shudhu single PUT er limit.
  • B. Bucket policy access permission dey; file size limit bodlay na.
  • D. Encryption security er jonno; upload size limit er sathe somporko nai.

Keyword: 25 GB file + upload errors → Multi-Part upload (> 5 GB must)

Instructor feedback (English)

A: The file size limit on S3 is 5 TB.

C: Multi-Part Upload is recommended as soon as the file is over 100 MB.
